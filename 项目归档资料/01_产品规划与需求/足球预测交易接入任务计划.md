# DeTrade 足球预测交易接入任务计划

> [!info] 背景
> 接入 Polymarket 足球类目的预测交易功能，为 6 月世界杯做准备。先只接入足球类目，完成列表页面设计。

---

## 一、Polymarket 足球页面调研结论

### 1.1 页面入口

| 入口 | URL | 说明 |
|------|-----|------|
| 足球比赛 | `/sports/soccer/games` | 比赛胜负相关市场 |
| 足球趣味投注 | `/sports/soccer/props` | 球员表现、特殊事件等道具投注 |

### 1.2 足球市场类型

| 类型 | 英文 | 说明 | 示例 |
|------|------|------|------|
| **比赛结果** | Match Result | 胜负平盘 | 曼联 胜 / 平局 / 切尔西 胜 |
| **让球** | Handicap | 让球盘 | 曼联 -0.5 / 切尔西 +0.5 |
| **进球数** | Total Goals | 大小球 | 大 2.5 / 小 2.5 |
| **双方进球** | BTTS | 两队均进球 | 是 / 否 |
| **冠军盘** | Outright | 赛事冠军 | 世界杯冠军 / 欧冠冠军 |
| **球员道具** | Player Props | 球员表现 | 姆巴佩进球数 / C罗助攻 |
| **半全场** | Half/Full Time | 半场+全场 | 半场平/全场胜 |
| **角球数** | Corners | 角球大小分 | 大 10.5 / 小 10.5 |

### 1.3 足球页面布局特点

**与网球的差异：**
- 足球比赛通常有**三个选项**：胜/平/负（不像网球只有胜负）
- 足球市场更丰富：除了胜负还有让球、进球数、双方进球、角球等
- 足球赛事按**联赛**分类（英超、西甲、德甲、意甲、法甲、欧冠、世界杯等）
- 足球市场交易量通常较大（热门比赛可达 $500K+）

## 六、交互逻辑说明

### 6.1 盘口点击逻辑

| 操作 | 响应 |
|------|------|
| 点击"曼联 胜" | 右侧面板显示：比赛结果 → 曼联 胜 → 45¢ |
| 点击"平局" | 右侧面板显示：比赛结果 → 平局 → 28¢ |
| 点击"切尔西 +0.5" | 右侧面板显示：让球 → 切尔西 +0.5 → 45¢ |
| 点击"大 2.5" | 右侧面板显示：进球数 → 大 2.5 → 62¢ |
| 点击"是(BTTS)" | 右侧面板显示：双方进球 → 是 → 68¢ |

### 6.2 交易面板状态

```
未选择 → 默认显示第一场比赛的第一个盘口
已选择 → 显示选中的盘口信息
金额输入 → 实时计算预估收益
点击买入 → 弹出确认弹窗 → 交易成功提示
```

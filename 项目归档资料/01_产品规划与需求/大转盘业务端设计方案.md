# 大转盘用户端业务设计方案 (User-Side Design Spec)

## 1. 设计目标
打造一个高互动性、强视觉冲击力的抽奖界面，作为用户完成任务后的核心激励出口。通过炫酷的动效和即时反馈，提升用户的留存率和任务完成率。

## 2. 视觉风格 (Visual Identity)
基于 Detrade 交易平台的暗色系风格，融入博彩/游戏化元素：
*   **主色调**: 深蓝/黑底色 (`#0B0E11`, `#1E2329`)。
*   **强调色**: 金色 (`#FCD535`) 代表财富/奖励，霓虹红/紫 (`#FF4D4D`, `#9D4EDD`) 用于活动氛围。
*   **质感**: 采用 3D 渲染或高光拟物风格的转盘主体，配合粒子特效。

## 3. 用户路径 (User Journey)

### 3.1 入口设计 (Entry Points)
1.  **任务中心 (Task Center)**:
    *   在任务列表顶部或完成任务后的 Toast 中，提示“获得 1 次抽奖机会”。
    *   常驻入口图标：“幸运大转盘”。
2.  **首页 Banner**:
    *   活动期间展示，点击直接进入转盘页。
3.  **悬浮球 (Floating Icon)**:
    *   仅在有可用抽奖次数时显示，增加紧迫感。

### 3.2 转盘主界面 (Main Interface)
*   **顶部**:
    *   返回按钮。
    *   活动标题 (可配置的 Banner 图片)。
    *   规则说明 (Icon + 弹窗)。
    *   我的奖品记录 (Icon + 弹窗)。
*   **中部 (核心)**:
    *   **转盘主体**: 8-10 格，展示奖品图标与名称。
    *   **启动按钮**: 位于转盘中心或下方，高亮显示“剩余次数”。
    *   **跑马灯**: “恭喜用户 138****8888 抽中 100 USDT”，营造中奖氛围。
*   **底部**:
    *   **次数获取引导**: “做任务赢次数” -> 跳转任务列表。
    *   **奖池预览**: 展示可能获得的大奖（吸引眼球）。

### 3.3 交互逻辑 (Interaction)
1.  **点击抽奖**:
    *   校验次数 -> 扣除次数 -> 播放转动动画 (Canvas/CSS 旋转) -> 减速停留在后端返回的奖品位置。
    *   *异常处理*: 网络错误时提示“网络开小差了”，不扣次数。
2.  **中奖反馈**:
    *   **弹窗**: 强烈的恭喜特效 (撒花/光效)。
    *   **内容**: 奖品图 + 名称 + “收入囊中”按钮 / “再抽一次”。
    *   **实物/优惠券**: 提示“已发放至卡券中心”或“联系客服”。
3.  **次数不足**:
    *   点击抽奖 -> 弹窗提示“次数不足” -> 展示推荐任务列表 (快速获取次数)。

# 商务角色代理管理系统 PRD

## 一、需求概述

### 1.1 背景

当前平台代理体系为一级代理和二级代理两级结构。为拓展业务渠道，新增"商务"角色层级，商务可自主管理其名下的一级代理，并协助一级代理开通二级代理角色。商务作为新增的渠道拓展角色，通过 NGR、PPL、UPDOWN 三种返佣模式获取收益。

### 1.2 目标

- 为运营团队提供商务数据查看和管理能力
- 为商务角色提供独立的 Dashboard 查看面板
- 完善代理体系的层级管理（商务 → 一级代理 → 二级代理 → 用户）
- 实现三种返佣模式（NGR、PPL、UPDOWN）的收益分润

### 1.3 返佣模式说明 [30]

| 模式     | 说明                         | 选择规则                           | **计算公式** |
| ------ | -------------------------- | ------------------------------ | ---------- |
| NGR    | Net Gaming Revenue，净游戏收入返佣 | 一级代理可选（单选/多选），二级代理根据所属一级代理模式继承 | **(盈利金额 + 亏损金额) × NGR返佣比例 = 返佣金额** |
| PPL    | Pay Per Lead，按有效用户返佣       | 一级代理可选（单选/多选），二级代理根据所属一级代理模式继承 | **(盈利金额绝对值 + 亏损金额绝对值) × PPL返佣比例 = 返佣金额** |
| UPDOWN | 涨跌玩法收益分润                   | **所有代理必选**，一级代理和二级代理均拥有        | 涨跌玩法收益 × UPDOWN返佣比例 = 返佣金额 |

**返佣模式选择规则：**

- 一级代理：**固定拥有 NGR+PPL+UPDOWN 三种返佣模式**（无需选择，系统默认分配），只需设置各模式的返佣比例
- 二级代理：继承所属一级代理的 NGR/PPL 模式（**单选**，不继承 UPDOWN），UPDOWN 为默认必选
- 示例：若一级代理拥有 NGR + PPL + UPDOWN 三种模式，则其下属二级代理可选择 NGR 或 PPL（单选）+ 默认 UPDOWN
- 返佣比例设置：
  - NGR：一级代理：2-70%，二级代理：1-69%
  - ppl：一级代理：0.2-1%，二级代理：0.1-0.9%，普通用户间邀请：固定0.3%
  - updown：一级代理：2-90%，二级代理：1-89%，普通用户 间邀请：固定 50%

## 二、角色层级关系 [31]

```
商务 (Business Development)
  ├── 一级代理 (Tier 1 Agent)
  │     ├── 二级代理 (Tier 2 Agent)
  │     │     └── 普通用户
  │     └── 普通用户
  └── (商务可直接发展一级代理)
```

| 字段       | 类型                      | 说明                              |
| -------- | ----------------------- | ------------------------------- |
| 所属一级代理   | -                       | 隐藏（不需要）                         |
| 返佣模式     | **固定显示** NGR+PPL+UPDOWN | 一级代理**固定拥有三种返佣模式**（无需选择），界面仅做展示 |
| NGR比例    | 输入框（必填）                 | 设置 NGR 模式的返佣比例，范围 0%-100%       |
| PPL比例    | 输入框（必填）                 | 设置 PPL 模式的返佣比例，范围 0%-100%       |

#### 3.5.5 二级代理专属字段

| 字段     | 类型                        | 说明                                                    |
| ------ | ------------------------- | ----------------------------------------------------- |

| 返佣模式   | 继承 NGR/PPL 单选 + UPDOWN 必选 | 仅继承所属一级代理的 NGR/PPL 模式（**单选**，不继承 UPDOWN），UPDOWN 为默认必选 |

**校验规则：**

- UID 必须为已注册用户
- 一级代理 UID 不能已是其他商务的一级代理
- 二级代理的所属一级代理必须属于所选商务
- 二级代理的佣金模式不能超过所属一级代理的模式范围
- 返佣比例范围 0%-100%
- 二级代理的返佣比例不能超过一级代理对应模式的比例

**字段顺序说明：**
添加代理弹窗中的字段顺序为：代理类型（添加代理/添加商务）→ 代理等级 → 所属商务 → 所属一级代理（仅二级代理显示）→ UID → 返佣模式及比例 → 备注

## 六、数据库设计建议

### 6.1 商务表 (bd\_agent)

```
- id: 主键
- uid: 用户 UID
- username: 商务名称
- status: 状态 (1:启用, 0:冻结)
- remark: 备注
- created_at: 注册时间
```

### 6.2 代理关系表 (agent\_relation)

```
- id: 主键
- bd_uid: 所属商务 UID
- agent_uid: 代理 UID
- agent_level: 代理等级 (1:一级, 2:二级)
- parent_agent_uid: 上级代理 UID（二级代理用）
- commission_modes: 佣金模式 (NGR,PPL,UPDOWN 逗号分隔，UPDOWN 必含)
- commission_rates: 各模式返佣比例 (JSON, 例: {"NGR":25, "PPL":15, "UPDOWN":30})
- remark: 备注
- status: 状态 (1:正常, 0:冻结)
- created_at: 创建时间
```

**commission\_modes 规则：**

- 一级代理：**固定包含 NGR、PPL、UPDOWN 三种模式**（不可变更），只需存储对应的比例值
- 二级代理：必须包含 UPDOWN，NGR/PPL 只能选择一个（从一级代理的 NGR/PPL 中单选）

**commission\_rates 存储示例：**

- 一级代理：{"NGR":25, "PPL":15, "UPDOWN":30}（三种模式都有比例值）
- 二级代理：{"NGR":15, "PPL":0, "UPDOWN":20} 或 {"NGR":0, "PPL":12, "UPDOWN":20}（未选的模式比例为0）

### 6.3 收益记录表 (commission\_record)

```
- id: 主键
- bd_uid: 商务 UID
- agent_uid: 代理 UID
- period: 收益周期
- ngr_amount: NGR 收益
- ppl_amount: PPL 收益
- updown_amount: UPDOWN 收益
- net_profit: 平台净利润
- created_at: 记录时间
```

# PRD：预测交易收藏夹功能产品需求文档

## 文档信息
- **版本**: v1.0
- **日期**: 2026-07-01
- **状态**: 初稿
- **目标**: 为平台预测交易模块新增收藏夹功能，支持用户收藏感兴趣的市场/事件，提升用户回访率和交易转化

---

## 1. 产品概述

### 1.1 背景

平台已接入 Polymarket 的预测交易功能与市场数据，涵盖足球（世界杯、五大联赛等）、加密货币、体育等类目。随着市场数量增长（192+ 活跃市场），用户需要一种方式快速定位和追踪自己感兴趣的市场，收藏夹功能应运而生。

### 1.2 竞品调研

**竞品：future.news/watchlist**

| 维度 | 竞品方案 | 我方差异化 |
|------|---------|-----------|
| 入口 | 顶部导航"追踪"Tab | 在左侧菜单 + 预测页面内双入口 |
| 收藏触发 | 事件详情页收藏按钮 | 事件列表卡片 + 交易详情页双位置收藏 |
| 展示内容 | 比赛列表（已结束/实时/即将开始） | 按分类 Tab 展示（体育/加密/政治等）+ 状态筛选 |
| 未登录态 | 显示"登录查看收藏夹" + 连接按钮 | 显示空状态 + 引导登录 |
| 实时数据 | 底部滚动 ticker 展示实时比分 | 收藏夹内嵌实时赔率更新 |

### 1.3 目标
- 为用户提供个性化的市场追踪工具
- 提升用户回访频次和交易转化率
- 降低用户在大量市场中查找目标市场的成本

### 1.4 目标用户
- 频繁交易的用户（需要快速访问常交易市场）
- 长期关注特定赛事/事件的用户（如世界杯全程追踪）
- 多市场同时关注的用户（同时关注足球 + 加密市场）

## 2. 功能模块详述

### 2.1 收藏触发

#### 2.1.1 事件列表卡片收藏

**触发位置**：每个事件/比赛卡片的右上角

**交互逻辑**：
- 未收藏状态：显示空心星形图标 ☆（或空心书签图标）
- 已收藏状态：显示实心星形图标 ★（或实心书签图标），高亮色
- 点击空心图标 → 加入收藏 → 变为实心 + Toast 提示"已加入收藏"
- 点击实心图标 → 取消收藏 → 变为空心 + Toast 提示"已取消收藏"

**未登录态处理**：
- 点击收藏按钮 → 弹出登录弹窗 → 登录成功后自动完成收藏操作

#### 2.1.2 交易详情页收藏

**触发位置**：交易详情页顶部标题栏右侧（与分享按钮并列）

**交互逻辑**：同 2.1.1

#### 2.2.3 分类 Tab

| Tab | 说明 | 数据来源 |
|-----|------|---------|

| 筛选 | 说明 |

| 全部 | 所有状态的市场 |

| 即将开始 | 尚未开始但即将开始的事件 |
| 已结束 | 已结算的事件 |

**交互**：点击筛选按钮，列表实时过滤

#### 2.2.5 收藏卡片展示

每张收藏卡片包含：
- 分类标签（体育/加密/政治等）+ 联赛/系列名称

- 事件状态（实时/即将开始/已结束）+ 时间
- 当前赔率（Yes/No 价格 + 百分比）
- 收藏按钮（实心状态，可点击取消）
- 点击卡片 → 跳转到交易详情页

#### 2.3.1 数据结构

```json

  "user_id": "user_123",

      "yes_price": 0.41,
      "no_price": 0.61
    }
```

#### 2.3.2 收藏上限
- 单用户最多收藏 **100** 个市场
- 达到上限时提示"收藏已满，请先取消部分收藏"

#### 2.3.3 数据同步
- 收藏数据实时同步到后端
- 多端登录时收藏状态保持一致
- 赔率数据通过 WebSocket 实时推送更新

## 3. 交互流程

### 3.1 收藏流程

```
用户点击收藏按钮
    │
    ├── 已登录 ──→ 调用收藏 API ─→ 更新 UI 状态 ──→ Toast 提示
    │
    └── 未登录 ──→ 弹出登录弹窗 ──→ 登录成功 ──→ 自动执行收藏 ──→ Toast 提示
                                      │
                                      └── 登录失败/取消 ──→ 不执行收藏
```

### 3.2 取消收藏流程

```
用户在收藏夹点击取消收藏
    │
    ├── 确认取消 ──→ 调用取消收藏 API ──→ 移除卡片 ─→ Toast 提示
    │
    ── 列表为空 ──→ 显示空状态
```

### 3.3 收藏夹页面导航流程

```
用户进入收藏夹页面
    │
    ├── 未登录 ──→ 显示未登录空状态
    │
    └── 已登录
        ├── 有收藏 ──→ 显示收藏列表
        │   ├── 切换分类 Tab
        │   ├── 切换状态筛选
        │   ├── 搜索收藏
        │   └── 点击卡片 → 跳转交易详情页
        │
        └── 无收藏 ──→ 显示已登录空状态
```

## 5. API 接口设计

### 5.1 收藏相关接口

#### 添加收藏
```
POST /api/v1/favorites
Body: {
  "market_id": "string",
  "event_id": "string",
  "title": "string",
  "category": "string"
}
Response: { "success": true, "favorite_id": "string" }
```

#### 取消收藏
```
DELETE /api/v1/favorites/{favorite_id}
Response: { "success": true }
```

#### 获取收藏列表
```
GET /api/v1/favorites?category=all&status=all&page=1&limit=20
Response: {
  "total": 10,
  "favorites": [...]
}
```

#### 查询收藏状态
```
GET /api/v1/favorites/status?market_id={market_id}
Response: { "is_favorited": true }
```

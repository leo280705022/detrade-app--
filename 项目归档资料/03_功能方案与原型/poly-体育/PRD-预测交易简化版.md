# PRD：预测交易简化版产品需求文档

## 文档信息
- **版本**: v1.0
- **日期**: 2026-07-13
- **状态**: 定稿
- **目标**: 将 Polymarket 美分价格转换为欧洲盘赔率格式，简化交易界面，降低用户理解门槛

---

## 1. 产品概述

### 1.1 背景

当前预测交易页面直接使用 Polymarket 的美分价格展示（如 Yes 70¢, No 31¢），用户理解成本较高。需要将美分价格转换为用户更熟悉的**欧洲盘/香港盘赔率格式**（如 1.43, 3.23），并参考竞品 BC.GAME 的简洁布局进行界面重构。

### 1.2 核心目标

| 目标 | 说明 |
|------|------|
| **降低理解门槛** | 将美分价格转换为直观的赔付倍率 |
| **简化交易流程** | 参考竞品设计，减少操作步骤 |
| **提升转化率** | 清晰的赔率展示 + 即时收益计算 |
| **统一体验** | 加密预测与体育预测使用相同的简化布局 |

## 2. 核心算法：美分价格 → 赔付倍率

### 2.1 转换公式

Polymarket 使用二进制 Yes/No 合约，价格范围 0-100¢，代表市场隐含概率。

**欧洲盘赔率（Decimal Odds）转换公式：**

```
赔付倍率 = 100 / 价格（美分）
```

**示例计算：**

| 选项 | 美分价格 | 隐含概率 | 赔付倍率 | 含义 |
|------|---------|---------|---------|------|
| Yes | 70¢ | 70% | 100/70 = **1.43** | 投$1，赢$1.43（含本金） |
| No | 31¢ | 31% | 100/31 = **3.23** | 投$1，赢$3.23（含本金） |

### 2.2 收益计算公式

```
总返还 = 投注金额 × 赔付倍率
净收益 = 投注金额 × (赔付倍率 - 1)
```

**示例：投注$100买Yes（倍率1.43）**
```
总返还 = $100 × 1.43 = $143.00
净收益 = $100 × (1.43 - 1) = $43.00
```

### 2.3 代码实现（JavaScript）

```javascript
function convertCentsToOdds(cents) {
    if (cents <= 0 || cents >= 100) return 0;
    const odds = 100 / cents;
    return Math.round(odds * 100) / 100;
}

function calculatePayout(betAmount, odds) {
    return Math.round(betAmount * odds * 100) / 100;
}

function calculateProfit(betAmount, odds) {
    return Math.round(betAmount * (odds - 1) * 100) / 100;
}
```

## 4. 交互逻辑

### 4.1 事件选择

| 操作 | 响应 |
|------|------|
| 点击加密事件卡片 | 卡片高亮，右侧交易面板更新事件信息 |
| 点击 Yes/No 选项 | 选中对应选项，显示赔付倍率，激活投注按钮 |
| 点击体育市场选项 | 选中对应盘口选项，显示赔付倍率，激活投注按钮 |
| 点击关闭按钮 | 清空交易面板，取消选中状态 |

### 4.2 交易流程

```
选择市场 → 选择选项 → 输入金额 → 确认投注 → 成功提示
     ↓          ↓           ↓           ↓          ↓
  卡片高亮   显示赔率   实时计算   二次确认   刷新列表
```

### 4.3 金额输入

| 操作 | 响应 |
|------|------|
| 手动输入金额 | 实时计算预计返还和收益 |
| 点击快捷金额按钮 | 填充对应金额，实时计算 |
| 输入无效金额 | 显示错误提示，禁用投注按钮 |

### 4.4 投注状态

| 状态 | 显示 | 操作 |
|------|------|------|
| 进行中 | 蓝色标签 | 无（等待结算） |
| 已获胜 | 绿色标签 | 显示"兑现"按钮 |
| 已失败 | 红色标签 | 无 |
| 已取消 | 灰色标签 | 无 |

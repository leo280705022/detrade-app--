# 渠道码与注册类型筛选下钻

**状态**: Draft | **版本**: V1.0 | **更新日期**: 2026-07-30 | **范围**: 增量业务

在充提流水页补充渠道码、注册类型筛选；在运营看板统计概览中，让"新增充值用户"和"充值用户数"卡片支持点击查看明细，并沿用同一组筛选条件。

---

## 问题与目标

运营在分析充值来源时，需要先从统计卡片看到结果，再按渠道码和注册类型定位用户或流水。当前统计概览只有汇总值，充提流水也无法用这两个维度筛选，导致"看见异常"和"查到明细"之间存在人工拼接。

### 本次要解决

让运营能够在同一日期范围内，以渠道码、注册类型组合筛选新增充值用户和全部充值用户；点击目标卡片后直接获得符合筛选条件的用户明细。

### 成功判断

筛选条件在两个页面命名、选项和组合逻辑一致；卡片数值与弹窗明细汇总一致；无匹配数据时给出明确空状态，不展示上一轮结果。

## 新增功能范围

| # | 页面 | 新增内容 | 业务逻辑 | 本次不变 |
|---|------|----------|----------|----------|
| 1 | 流水记录 - 充提流水 | 渠道码、注册类型两个筛选条件 | 与现有筛选条件一起提交；多个条件为 AND 关系。重置时清空新增条件并恢复默认查询。 | 原有类型、状态、时间、用户 ID、币种、订单 ID、导出和表格字段沿用。 |

## 业务规则

### 筛选条件

| 字段 | 控件 | 默认值 | 规则 |
|------|------|--------|------|
| 渠道码 | 文本输入 | 空（不筛选） | 用户手动输入渠道码；输入后按用户注册归属渠道精确匹配；为空时不携带过滤参数，等同于全部。 |
| 注册类型 | 下拉选择 | 全部 | 选项至少包含普通注册、第三方注册；实际选项以现有注册类型字典为准。 |
| 日期 | 日期选择器 | 沿用当前页面默认值 | 卡片弹窗继承统计概览当前日期；流水页沿用流水页日期条件。 |

### 统计口径

**"新增充值用户"** 按统计日期内完成首笔成功充值且注册日期落在统计日期范围内的用户去重计数。渠道码和注册类型均按用户维度过滤，用户没有渠道码时归入"无渠道码"，不因空值被隐藏。

**"充值用户数"** 按统计日期内完成过至少一笔成功充值的去重用户计数，不限注册时间。渠道码和注册类型同样按用户维度过滤。该指标与"新增充值用户"的区别在于：新增充值用户仅统计注册日期落在统计范围内的用户，充值用户数统计所有在统计日期内有成功充值记录的用户（含老用户）。

## 功能要求

### 1. 充提流水新增筛选

进入充提流水页后，在现有筛选区新增"渠道码"和"注册类型"两个控件，位置接在现有用户 ID 之后。筛选区完整控件顺序为：类型、状态、时间范围、用户 ID、**渠道码（文本输入）**、**注册类型（下拉选择）**、币种、订单 ID。

用户可以单独填写任一条件，也可以与类型、状态、时间范围、用户 ID、币种、订单 ID 组合查询。点击查询后，系统使用所有已填写条件刷新表格并回到第一页；查询按钮进入加载状态期间不可重复提交。点击重置后，渠道码清空、注册类型恢复"全部"，同时清空其他查询条件并恢复现有默认状态。渠道码为空时不携带过滤参数；注册类型使用字典值提交。没有匹配数据时表格展示"暂无符合条件的流水记录"，不保留上一次查询结果。

筛选区下方显示当前新增筛选条件摘要，格式为：`新增筛选：渠道码 = {值} · 注册类型 = {值}`，未填写时显示"全部"。

### 2. 统计卡片点击与筛选

统计概览筛选区在现有日期选择器后新增两个控件：**渠道码（文本输入）**、**注册类型（下拉选择）**。筛选区下方显示当前统计范围摘要，格式为：`当前统计范围：{日期} · 渠道码：{值} · 注册类型：{值}`。

"新增充值用户"和"充值用户数"两张卡片增加可点击态和 hover 态，卡片底部显示"点击查看用户明细 "提示文案。其余卡片（充值用户人均、提现用户）保持不可点击。

点击任一可点击卡片后打开对应标题的明细弹窗，弹窗默认继承当前统计日期、当前渠道码和注册类型；若当前页面渠道码或注册类型为空，则摘要显示"全部"。弹窗顶部提供渠道码（文本输入）、注册类型（下拉选择）两个筛选控件及查询、重置按钮，点击查询只刷新弹窗内容，不关闭弹窗，并同步更新顶部汇总值。

弹窗关闭后，统计概览原页面筛选条件与卡片数值不被意外改写；若用户在弹窗内应用了筛选，关闭弹窗后再次打开仍以统计概览页面条件为准，避免局部条件污染全局。

### 3. 明细弹窗

弹窗顶部展示筛选摘要行，包含四项信息：统计日期、渠道码、注册类型、当前汇总（人数）。

弹窗筛选区提供渠道码（文本输入）和注册类型（下拉选择）两个控件，支持在弹窗内二次筛选。

明细表格字段如下：

| 字段 | 说明 |
|------|------|
| 用户 ID | 用户唯一标识 |
| 注册时间 | 用户注册日期时间 |
| 注册类型 | 普通注册 / 第三方注册 |
| 渠道码 | 用户归属渠道码，无渠道码时显示"无渠道码" |
| 充值金额 | 充值金额数值 |
| 状态 | 充值状态标签 |

新增充值用户卡片弹窗展示去重后的新增充值用户明细；充值用户数卡片弹窗展示去重后的全部充值用户明细（含老用户），字段相同。分页沿用后台表格组件，每页数量沿用现有默认值。返回空数据时展示"暂无符合条件的明细"，同时汇总值显示 0，不允许沿用打开弹窗前的数字。

> **关键取舍：** V1 只支持渠道码与注册类型筛选和明细查看，不新增导出、明细跳转用户详情、渠道码配置和注册类型管理。先验证运营是否通过这两个维度完成定位，再决定是否扩大统计下钻范围。

## 交互原型

原型沿用现有后台管理框架的深色左侧导航、白色顶部标签栏、浅灰内容区和表格组件。

**可点击操作**：

- 左侧导航切换"统计概览"和"充提流水"两个页面
- 两个页面均可应用筛选（查询/重置）
- 统计概览中点击"新增充值用户"或"充值用户数"卡片打开明细弹窗
- 弹窗内可再次筛选（查询/重置）
- 点击"×"或"关闭"按钮关闭弹窗

> 交互原型详见同目录下的 `原型-渠道码与注册类型筛选.html`。

## 验收口径

| 场景 | 预期结果 |
|------|----------|
| 统计概览输入渠道码、选择注册类型后点击查询 | 两个新增卡片的数值按组合条件刷新；卡片可点击。 |
| 点击新增充值用户卡片 | 打开新增充值用户明细弹窗，继承日期、渠道码、注册类型，展示去重新增充值用户及汇总数。 |
| 点击充值用户数卡片 | 打开充值用户数明细弹窗，继承筛选，展示全部去重充值用户（含老用户）及汇总数。 |
| 弹窗内修改渠道码或注册类型并查询 | 只刷新弹窗数据和汇总，弹窗不关闭；筛选摘要同步变化。 |
| 充提流水组合查询 | 渠道码、注册类型与其他条件共同生效，查询结果回到第一页。 |
| 无匹配数据 | 汇总显示 0，表格显示空状态文案，不保留上一轮结果。 |
| 查询接口异常或权限不足 | 保留当前筛选，提示失败原因；不覆盖当前已展示数据。 |

## 待确认事项

以下内容影响最终接口字段，但不影响原型评审：

- 渠道码输入后是精确匹配还是模糊匹配
- 注册类型的完整枚举及历史用户缺失值展示
- 运营角色是否继续沿用现有统计概览和充提流水权限

> 建议在开发前由数据/后端确认统计 SQL 口径，"新增充值用户"仅统计注册日期落在统计范围内的首充用户，"充值用户数"统计统计日期内所有有成功充值记录的去重用户（不限注册时间），并用同一查询条件返回卡片汇总和弹窗列表，避免前后端各自计算产生对不上账。

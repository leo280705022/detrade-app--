# Detrade 登录注册流程重构 PRD

## 一、项目背景

### 1.1 现状分析
当前 Detrade 平台的登录注册流程存在以下问题：
- **注册与登录完全合并**：按钮文案"注册/登录"模糊，新用户缺乏明确引导
- **营销内容单薄**：仅 2 句文案轮播，缺少产品特性展示和信任背书
- **第三方登录图标无标签**：5 个图标无文字说明，用户需猜测平台
- **密码登录入口不突出**：视觉权重低，容易被忽略
- **缺少 Apple 登录**：iOS 用户体验不佳
- **无"记住我"功能**：每次需重新输入密码
- **安全提示不明显**：reCAPTCHA 声明字体过小

### 1.2 重构目标
- 提升注册转化率 20%+
- 降低登录流程摩擦
- 增强安全感和信任度
- 优化营销内容展示
- 支持更多登录方式（Apple、扫码登录）

---

## 二、用户画像

### 2.1 新用户
- **特征**：首次访问平台，对加密货币交易感兴趣
- **痛点**：担心安全性、不清楚平台价值、注册流程复杂
- **需求**：快速注册、了解平台优势、获得新用户奖励

### 2.2 老用户
- **特征**：已有账户，需要快速登录
- **痛点**：忘记密码、每次都要输入密码、担心账户安全
- **需求**：快速登录、记住登录状态、多重安全保障

### 2.3 Web3 用户
- **特征**：习惯使用加密钱包，注重隐私和去中心化
- **痛点**：传统注册流程繁琐、不想暴露个人信息
- **需求**：钱包一键登录、无需传统注册

## 三、功能设计

### 3.1 注册流程

#### 3.1.1 支持的注册方式
1. **邮箱注册**（主推）
   - 输入邮箱 → 获取验证码 → 设置密码 → 完成
   - 验证码 5 分钟有效，60 秒可重发

2. **第三方快捷注册**
   - Google 账号（一键授权）
   - Apple ID（一键授权，iOS 必备）
   - Telegram 账号（一键授权）
   - Web3 钱包（MetaMask、WalletConnect）

#### 3.1.2 注册步骤优化
**当前流程（5 步）**：
```
输入邮箱 → 点击注册/登录 → 接收验证码 → 输入验证码 → 完成
```

**优化后流程（3 步）**：
```
选择注册方式 → 填写信息（邮箱/手机/第三方授权）→ 设置密码 → 完成
```

**关键优化点**：
- 邮箱/手机号注册时，验证码输入和密码设置合并为一步
- 第三方注册无需设置密码（由第三方平台管理）
- 注册成功后自动登录，无需二次操作

#### 3.1.3 密码要求
- **长度**：8-32 位
- **复杂度**：至少包含 1 个大写字母 + 1 个小写字母 + 1 个数字
- **强度提示**：实时显示密码强度（弱/中/强）
- **安全建议**：提示用户不要使用与其他平台相同的密码

#### 3.1.4 邀请码机制
- **位置**：密码字段下方，标注"邀请码（选填）"
- **自动填充**：通过邀请链接注册时自动填入
- **奖励展示**：输入邀请码后显示"您将获得 XX 奖励"

#### 3.1.5 KYC 策略（完全可选）
- **注册时**：不要求 KYC
- **交易时**：不要求 KYC，注册后即可直接交易
- **提现时**：不要求 KYC，可直接提现
- **KYC 定位**：完全可选的增值服务，非必须完成
- **KYC 激励**：
  - 完成 KYC 可获得额外奖励（如 $10 代金券）
  - 提升账户安全等级
  - 解锁更高提现额度（如有需要）
- **引导时机**：
  - 注册成功后欢迎弹窗中提示（可跳过）
  - 个人中心设置页面（非强制）

### 3.2 登录流程

#### 3.2.1 支持的登录方式
1. **邮箱 + 密码登录**
2. **邮箱 + 验证码登录**（免密登录）
3. **第三方快捷登录**
   - Google
   - Apple
   - Telegram
   - Web3 钱包
4. **App 扫码登录**（新增）
   - 移动端 App 扫描 Web 端二维码
   - 安全性高，无需在 Web 端输入密码

#### 3.2.2 登录页面设计
**页面结构**：
- **左侧（60%）**：营销展示区
  - 品牌 Logo 水印
  - 产品特性卡片轮播（3-5 张）
  - 安全认证标识（SSL、合规牌照、冷存储等）
  - 用户数据展示（注册用户数、日交易量等）
  
- **右侧（40%）**：登录表单卡片
  - Tab 切换：登录 / 注册
  - 登录方式切换：密码登录 / 验证码登录
  - 第三方登录按钮（带文字标签）
  - "记住我"复选框
  - "忘记密码"链接

#### 3.2.3 登录安全验证
- **反机器人验证**：滑块拼图 CAPTCHA（首次登录或异常 IP）
- **二次验证（2FA）**：
  - Google Authenticator（推荐）
  - 短信验证码
  - 邮箱验证码
- **异常登录检测**：
  - 新设备登录 → 发送邮箱通知
  - 异常 IP → 要求额外验证
  - 频繁失败 → 临时锁定账户

#### 3.2.4 登录状态保持
- **记住我**：勾选后 30 天内免登录
- **设备管理**：
  - 查看已登录设备列表
  - 远程踢出可疑设备
  - 常用设备标记

### 3.3 忘记密码流程

#### 3.3.1 重置步骤
1. 输入注册邮箱/手机号
2. 获取验证码
3. 输入验证码 + 设置新密码
4. 完成重置，自动登录

#### 3.3.2 安全保护
- 验证码 5 分钟有效
- 24 小时内最多重置 3 次
- 重置后发送邮箱通知
- 所有设备强制退出登录

### 3.4 营销内容设计

#### 3.4.1 登录页营销展示
**左侧区域内容**：
1. **首充奖励**（核心）
   - 标题："首充翻倍，最高 $100"
   - 副标题："新用户首次充值即享 100% 奖励"
   - CTA 按钮："立即注册"
   
2. **产品特性卡片**（轮播）
   - 卡片 1：交易品种（合约、预测、跟单）
   - 卡片 2：安全认证（SSL、冷存储、合规牌照）
   - 卡片 3：用户数据（100 万+注册用户、$10 亿日交易量）
   - 卡片 4：客户支持（7x24 小时在线客服）

3. **信任背书**
   - 安全认证图标：SSL 加密、PCI DSS、GDPR
   - 合规牌照展示（如有）
   - 合作伙伴 Logo

#### 3.4.2 注册成功后引导
1. **欢迎弹窗**
   - 标题："欢迎加入 Detrade！"
   - 内容："您已获得 XX 新人奖励"
   - CTA 按钮："立即领取" / "开始交易"

2. **新手任务**（全部可选）
   - 首次充值 → 获得 100% 奖励（最高 $100）
   - 首笔交易 → 获得手续费返还
   - 完成 KYC → 获得 $10 代金券（可选增值服务）

3. **引导流程**（注册后即可直接交易）
   - 步骤 1：首次充值（展示奖励，可跳过）
   - 步骤 2：开始交易（引导至交易页面）
   - 可选：完成 KYC 获得额外奖励（个人中心随时完成）
   - 可选：绑定 2FA 提升账户安全

## 五、安全特性

### 5.1 反机器人验证
- **触发条件**：
  - 首次登录
  - 异常 IP 地址
  - 频繁登录失败
  - 自动化脚本检测

- **验证方式**：滑块拼图 CAPTCHA
  - 用户拖动滑块完成拼图
  - 验证通过后方可继续登录

### 5.2 二次验证（2FA）
- **支持方式**：
  - Google Authenticator（推荐）
  - 短信验证码
  - 邮箱验证码

- **启用场景**：
  - 新设备登录
  - 异常 IP 登录
  - 提现操作
  - 修改安全设置

### 5.3 设备管理
- **功能**：
  - 查看已登录设备列表（设备名称、IP、登录时间）
  - 远程踢出设备
  - 标记常用设备
  - 新设备登录通知（邮件/短信）

### 5.4 资金密码
- **用途**：提现、转账等敏感操作
- **要求**：独立于登录密码，6 位数字
- **设置时机**：首次提现前强制设置

### 5.5 防钓鱼码
- **功能**：用户设置个性化防钓鱼码
- **作用**：所有来自 Detrade 的邮件都会显示该码
- **效果**：帮助用户识别钓鱼邮件

## 七、上线计划

### 7.1 阶段划分

#### Phase 1：基础优化（2 周）
- 登录/注册 Tab 切换
- 第三方登录添加文字标签
- 添加"记住我"功能
- 优化密码登录入口视觉
- 丰富营销内容展示

#### Phase 2：功能增强（2 周）
- 添加 Apple 登录
- 添加验证码免密登录
- 添加扫码登录
- 优化忘记密码流程
- 添加设备管理功能

#### Phase 3：安全升级（2 周）
- 滑块 CAPTCHA 验证
- 2FA 验证器集成
- 资金密码功能
- 防钓鱼码功能
- 异常登录检测

#### Phase 4：数据驱动（持续）
- A/B 测试不同页面布局
- 优化注册流程步骤
- 个性化营销内容
- 智能风控策略

### 7.2 灰度发布
- **灰度比例**：10% → 30% → 50% → 100%
- **灰度策略**：按用户 ID 尾号灰度
- **回滚方案**：发现问题立即回滚至旧版本

## 八、风险与应对

### 8.1 技术风险
- **风险**：第三方登录接口不稳定
- **应对**：添加降级策略，接口失败时提示用户使用其他方式

### 8.2 安全风险
- **风险**：验证码被恶意刷取
- **应对**：限制发送频率（60 秒）、限制每日发送次数、添加图形验证码

### 8.3 用户体验风险
- **风险**：新流程过于复杂
- **应对**：A/B 测试验证，收集用户反馈，持续优化

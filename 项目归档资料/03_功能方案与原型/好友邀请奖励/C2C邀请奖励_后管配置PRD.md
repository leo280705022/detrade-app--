## 1. 概述

### 1.1 页面模式

采用**列表页 + 弹窗**的标准 CRUD 模式：
- **活动列表页**：展示所有活动（含当前进行中 + 全部历史），支持筛选、新建、编辑、上下线、复制
- **新建/编辑弹窗**：配置活动的基本信息、阶梯奖励、邀请条件和风控策略

### 1.2 菜单位置

```
活动管理
├── ...
├── C2C 邀请奖励    ← 新增菜单项
├── ...

代理中心（不变）
├── 普通邀请管理    ← 现有功能保留
└── ...
```

## 2. 活动列表页

### 2.1 筛选条件

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 活动状态 | 下拉 | 全部 / 未上线 / 已上线 / 已下线 / 已结束 |
| 活动名称 | 输入框 | 模糊搜索 |

### 2.2 列表字段

| 字段 | 说明 |
|------|------|
| 活动 ID | 唯一标识 |
| 活动名称 | |
| 状态 | 未上线 / 已上线 / 已下线 / 已结束 |
| 活动时间 | 开始 ~ 结束 |
| 有效邀请 / 参与用户 | 合并为一列，如 "256 / 1,024" |
| 累计奖励 (USDT) | 已发放总金额 |
| 操作 | 根据状态显示不同按钮 |

### 2.3 操作按钮（按状态）

| 状态 | 可用操作 |
|------|---------|
| 未上线 | 编辑 / 上线 / 删除 |
| 已上线 | 查看 / 下线 |
| 已下线 | 查看 / 复制 / 上线 |
| 已结束 | 查看 / 复制 |

### 2.4 操作说明与异常分支

> 核心约束：**全局仅允许一个活动处于「已上线」状态**

#### 上线操作

| 场景 | 处理 |
|------|------|
| 正常：无在线活动，配置完整 | 上线成功 |
| 异常：已有在线活动「XXX」 | **报错**：「当前已有活动「XXX」在线，请先下线后再操作」 |
| 异常：活动结束时间已过期 | **报错**：「活动结束时间已过期，请修改后再上线」 |
| 异常：未配置阶梯奖励 | **报错**：「请至少配置一个奖励阶梯」 |
| 异常：开始时间 > 结束时间 | **报错**：「开始时间不能晚于结束时间」 |

#### 下线操作

| 场景 | 处理 |
|------|------|
| 正常：活动在线 | 弹出确认框后下线 |
| 确认框 | 「下线后用户将无法看到该活动，已产生的邀请记录继续有效。确认下线？」 |
| 提示 | 若有待发放奖励，追加提示：「该活动仍有 X 笔待发放奖励，下线后不会自动发放」 |

#### 编辑操作

| 场景 | 处理 |
|------|------|
| 未上线 | 打开弹窗，可修改所有字段 |
| 已上线 | 打开弹窗，**仅结束时间可编辑**，其余字段置灰只读 |
| 已下线 | 打开弹窗，可修改所有字段 |
| 已结束 | **不可编辑**，列表中不显示编辑按钮，仅有「查看」 |

#### 删除操作

| 场景 | 处理 |
|------|------|
| 未上线，无邀请记录 | 弹出确认框后删除 |
| 未上线，但已有邀请记录 | **不可删除**：「该活动已有邀请记录，无法删除」 |
| 已上线 | **不可删除**，需先下线 |
| 已下线/已结束，有邀请记录 | **不可删除**：「该活动已有历史数据，无法删除」 |
| 确认框 | 「确认删除活动「XXX」？删除后不可恢复」 |

#### 复制操作

| 场景 | 处理 |
|------|------|
| 正常 | 复制配置创建新活动（未上线状态），名称自动加后缀「- 副本」 |
| 注意 | 复制后时间清空，需手动设置新的活动时间 |

#### 新建操作（保存时校验）

| 校验项 | 报错信息 |
|--------|---------|
| 活动名称为空 | 「请输入活动名称」 |
| 未设置时间 | 「请设置活动时间」 |
| 结束时间 <= 开始时间 | 「结束时间必须晚于开始时间」 |
| 无阶梯奖励 | 「请至少配置一个奖励阶梯」 |
| 阶梯邀请人数非递增 | 「阶梯邀请人数必须递增」 |
| 阶梯金额 <= 0 | 「奖励金额必须大于 0」 |

### 2.5 时间自动状态变更

| 场景 | 处理 |
|------|------|
| 活动结束时间到达 | 系统自动将状态从「已上线」变为「已结束」 |
| 列表加载时 | 自动检查所有「已上线」活动，过期的自动标记为「已结束」 |
| 已上线活动被手动改结束时间为过去 | 保存后立即变为「已结束」 |

## 3. 新建/编辑弹窗

弹窗内分 3 个区块，上下排列直接滚动：

### 3.1 区块 A：基本信息

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 活动名称 | 文本 | 是 | 后台管理用 |
| 活动时间 | 日期时间范围 | 是 | 开始 ~ 结束，合并为一个字段 |

### 3.2 区块 B：阶梯奖励

| 列 | 类型 | 说明 |
|----|------|------|
| 阶梯序号 | 自动生成 | 按行号自增 |
| 阶梯邀请人数完成 | 数字输入 | 该阶梯需完成的有效邀请人数 |
| 奖励类型 | 下拉选择 | 真金 / 奖励金 / 优惠券 |
| 奖品 | 动态 | 奖励类型为「真金/奖励金」时：数字输入（USDT 金额）；奖励类型为「优惠券」时：下拉选择已配置的优惠券 |
| 操作 | 按钮 | 删除 |

- 底部：「+ 添加阶梯」按钮
- 右侧汇总：自动计算累计奖励上限（仅统计真金/奖励金类型）
- 校验：邀请人数递增、金额 > 0、至少 1 个阶梯、最多 20 个
- 选择「优惠券」时底部显示提示：「选择优惠券类型的阶梯，将从已配置的优惠券列表中拉取」

### 3.3 区块 C：邀请条件 & 风控

**邀请条件：**

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 首次充值门槛 | 数字输入 | 20 | 单位 USDT |
| 交易额门槛 | 数字输入 | 200 | 单位 USDT |

**风控开关：**

| 字段 | 类型 | 默认值 |
|------|------|--------|
| IP 校验 | 开关 | 开启 |
| 钱包地址校验 | 开关 | 开启 |
| 设备指纹校验 | 开关 | 开启 |
| 单日邀请上限 | 数字输入 | 20 |

**自定义规则（可选）：**

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 自定义规则内容 | 多行文本 | 空 | 支持中英文。填写后业务端优先展示此内容，替代自动生成的规则文案。为空时业务端按模板自动生成 |

> 自动生成模板：
> - EN: "Invite friends to register. Each friend must complete a first deposit of {deposit} USDT and trading volume of {trade} USDT to count as a valid invite. Rewards are automatically distributed to your balance upon reaching each tier threshold."
> - ZH: "邀请好友注册，每位好友需完成首次充值 {deposit} USDT 且交易额达到 {trade} USDT 方计为有效邀请。达到阶梯条件后奖励自动发放至账户余额。"

### 3.4 弹窗模式

| 模式 | 触发方式 | 说明 |
|------|---------|------|
| 新建 | 列表页「+ 新建活动」按钮 | 空白表单 |
| 编辑 | 列表页「编辑」按钮 | 可修改所有字段 |
| 查看 | 列表页「查看」按钮 | 只读，隐藏保存按钮 |

## 7. 注意事项

1. **活动唯一性**：同一时间仅允许一个活动处于「已上线」状态
2. **上线后限制编辑**：已上线活动仅可修改结束时间，其他需先下线
3. **与现有页面兼容**：普通邀请管理和反佣概览的现有功能完全不动
4. **奖励发放不可逆**：已发放奖励不可回收

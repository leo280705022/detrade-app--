# K 线全屏下单功能 PRD 文档

## 1. 产品概述

### 1.1 背景

基于对主流 CEX 平台（Binance、OKX、Bybit、Bitget、Gate.io）K 线全屏下单功能的调研，结合 DeTrade 平台三种核心玩法（Futures、High Low、Spread）的业务特性，设计全屏 K 线下单功能，提升专业交易用户的盯盘和下单效率。

### 1.2 核心目标

- 提供沉浸式全屏 K 线交易体验，支持三种玩法的差异化功能
- 优化下单流程，支持快捷操作和图表直接下单
- 完善订单管理和持仓展示，适配各玩法业务逻辑
- 支持中英文双语切换

### 1.3 适用范围

- **Futures（合约交易）**：逐仓模式，独立底单，不支持加仓
- **High Low（高低价预测）**：短时间二元预测，不同时间 ROI 不同
- **Spread（差价预测）**：多时间选择，不同时间不同点差和 ROI

## 2. 全屏 K 线界面布局

### 2.1 通用布局结构

```
┌─────────────────────────────────────────────────────────────┐
│ 顶部导航栏（交易对选择、价格、涨跌幅、全屏切换按钮）            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│                    K 线图区域（50-60%）                       │

│              - 显示订单线、持仓线、强平线                      │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│ 订单簿（右侧）    │  下单面板（右侧）  │  成交记录（右侧）      │
│  - 买卖挂单       │  - 订单类型       │  - 最近成交           │
│  - 深度图         │  - 价格/数量输入   │  - 价格/数量/时间     │
│  - 点击价格填入   │  - 买入/卖出按钮   │                      │

│ 底部标签页区域                                                │

```

### 2.2 全屏模式特性

| 功能 | 说明 |
|------|------|
| 进入方式 | 点击 K 线图右上角全屏图标 |
| 退出方式 | 按 ESC 键或点击退出全屏图标 |
| 界面变化 | 隐藏顶部导航栏和侧边栏，K 线图占据最大区域 |
| 下单面板 | 可展开/收起，默认展开 |
| 订单簿 | 可展开/收起，默认展开 |
| 快捷键 | 全屏模式下持续生效 |

### 2.3 响应式设计

| 屏幕宽度 | 布局调整 |
|---------|---------|
| ≥1920px | 完整布局，所有模块可见 |
| 1440-1919px | 订单簿和下单面板合并为右侧面板 |
| 1280-1439px | 隐藏成交记录，仅显示订单簿和下单面板 |
| <1280px | 提示用户使用更大屏幕获得最佳体验 |

## 3. Futures（合约交易）全屏下单

### 3.1 业务特性

| 特性 | 说明 |
|------|------|
| 保证金模式 | 逐仓模式（Isolated Margin） |
| 持仓方式 | 每笔订单独立底单，不支持加仓 |
| 均价计算 | 无均价概念，每笔订单独立计算 |
| 强平价格 | 仅与杠杆相关，与仓位大小无关 |
| 杠杆范围 | 1x - 1000x |
| 订单类型 | 限价单、市价单、止损单、止盈单、追踪止损 |

### 3.2 全屏界面功能

#### 3.2.1 K 线图区域

| 功能 | 说明 |
|------|------|
| 价格线 | 显示标记价格线（橙色）和最新价格线（白色） |
| 持仓线 | 在图表上显示持仓开仓价水平线（绿色=多头，红色=空头） |
| 强平线 | 显示强平价格水平线（红色虚线） |
| 订单线 | 显示挂单价格水平线（蓝色=买入，橙色=卖出） |
| 订单线拖拽 | 支持拖拽订单线调整价格（仅限价单） |
| TP/SL 线 | 支持在图表上拖拽设置止盈止损价格 |

#### 3.2.2 下单面板

**订单类型 Tab：**

| Tab | 功能 |
|-----|------|
| 限价单 | 价格输入框、数量输入框、买入/卖出按钮 |
| 市价单 | 数量输入框、买入/卖出按钮 |
| 止损单 | 触发价格、委托价格、数量、买入/卖出按钮 |
| 止盈单 | 触发价格、委托价格、数量、买入/卖出按钮 |
| 追踪止损 | 回调比例、触发价格、数量、买入/卖出按钮 |

**杠杆设置：**

| 功能 | 说明 |
|------|------|
| 杠杆滑块 | 1x - 1000x 滑块选择 |
| 杠杆输入框 | 直接输入杠杆数值 |
| 快捷档位 | 1x、10x、50x、100x、200x、500x、1000x |
| 风险等级标识 | 绿色（1-100x）、黄色（101-200x）、橙色（201-500x）、红色（501-1000x） |

**金额设置：**

| 功能 | 说明 |
|------|------|
| 金额输入框 | USDT 金额输入 |
| 百分比快捷按钮 | 25%、50%、75%、100% |
| 可用余额显示 | 显示当前可用余额 |
| 强平价格显示 | 买入/卖出按钮下方分别显示对应强平价格 |

#### 3.2.3 持仓记录（底部标签页）

**持仓列表字段：**

| 字段 | 说明 |
|------|------|
| 交易对 | 合约交易对名称 |
| 方向 | 多头（绿色）/ 空头（红色） |
| 杠杆 | 当前订单杠杆倍数 |
| 开仓价 | 该笔订单开仓价格 |
| 数量 | 该笔订单持仓数量 |
| 持仓价值 | 按标记价格计算的名义价值 |
| 标记价格 | 用于计算强平的公允价格 |
| 未实现盈亏 | 按当前价格计算的浮动盈亏（uPnL） |
| 收益率 | 持仓收益率百分比（ROE） |
| 强平价格 | 该笔订单的强平触发价格 |
| 操作 | 平仓、调整 TP/SL |

**特殊说明：**
- 每笔订单独立显示，不合并计算均价
- 支持按交易对筛选
- 支持按方向筛选（多头/空头）
- 支持批量平仓

#### 3.2.4 当前委托（底部标签页）

**委托列表字段：**

| 字段 | 说明 |
|------|------|
| 交易对 | 合约交易对名称 |
| 订单类型 | 限价/市价/止损/止盈/追踪止损 |
| 方向 | 买入/卖出 |
| 委托价格 | 挂单价格 |
| 数量 | 委托数量 |
| 已成交 | 已成交数量 |
| 未成交 | 未成交数量 |
| 触发价格 | 条件单触发价格 |
| 委托时间 | 下单时间 |
| 操作 | 撤单、编辑 |

**功能：**
- 支持按交易对筛选
- 支持按订单类型筛选
- 支持全部撤单
- 支持点击订单在图表上显示订单线

### 3.3 Futures 特色功能

| 功能 | 说明 |
|------|------|
| 资金费率 | 在顶部显示当前资金费率和倒计时 |
| 保证金计算器 | 点击计算器图标打开保证金计算器弹窗 |
| 一键反手 | 快捷键一键反手当前持仓方向 |
| 快捷平仓 | 持仓列表支持一键平仓按钮 |
| 图表直接下单 | 在图表价格刻度上点击拖动设置限价单 |

## 4. High Low（高低价预测）全屏下单

### 4.1 业务特性

| 特性 | 说明 |
|------|------|
| 预测方式 | 预测价格在指定时间内是否突破行权价 |
| 结果类型 | 二元结果（高/低） |
| 时间范围 | 30 秒、1 分钟、5 分钟、15 分钟、30 分钟、1 小时 |
| ROI 差异 | 不同时间范围对应不同 ROI 收益率 |
| 赔付比例 | 固定赔付比例（如 88%-200%） |
| 订单模式 | 做市商模式，无传统订单簿 |

### 4.2 全屏界面功能

#### 4.2.1 K 线图区域

| 功能 | 说明 |
|------|------|
| 行权价线 | 在图表上显示行权价水平线（黄色虚线） |
| 倒计时显示 | 在图表右上角显示当前预测倒计时 |
| 价格距离 | 显示当前价格与行权价的距离（百分比） |
| 预测区域 | 行权价上方绿色区域（预测高），下方红色区域（预测低） |

#### 4.2.2 下单面板

**时间选择：**

| 时间 | ROI | 赔付比例 |
|------|-----|---------|
| 30 秒 | 85% | 185% |
| 1 分钟 | 88% | 188% |
| 5 分钟 | 90% | 190% |
| 15 分钟 | 92% | 192% |
| 30 分钟 | 95% | 195% |
| 1 小时 | 100% | 200% |

**下单区域：**

| 功能 | 说明 |
|------|------|
| 行权价输入 | 自定义行权价或选择默认行权价 |
| 投入金额 | USDT 金额输入 |
| 预期收益 | 根据投入金额和 ROI 实时计算 |
| 高（Higher）按钮 | 绿色大按钮，预测价格会上涨突破行权价 |
| 低（Lower）按钮 | 红色大按钮，预测价格会下跌突破行权价 |
| 1-Click 下单 | 开启后无需确认直接下单 |

**数据显示：**

| 数据 | 说明 |
|------|------|
| 当前胜率 | 显示当前时间范围的实时胜率 |
| 交易情绪 | 显示其他用户的选择比例（高/低） |
| 历史结果 | 显示最近 10 期的开奖结果 |

#### 4.2.3 持仓记录（底部标签页）

**当前预测列表字段：**

| 字段 | 说明 |
|------|------|
| 交易对 | 预测交易对名称 |
| 方向 | 高（Higher）/ 低（Lower） |
| 行权价 | 预测的行权价格 |
| 投入金额 | 投入的 USDT 金额 |
| 预期收益 | 预期获得的收益 |
| 到期时间 | 预测到期时间 |
| 倒计时 | 剩余时间倒计时 |
| 当前状态 | 进行中 / 已结算 |
| 操作 | 查看详情 |

**历史结果列表字段：**

| 字段 | 说明 |
|------|------|
| 交易对 | 预测交易对名称 |
| 方向 | 高 / 低 |
| 行权价 | 行权价格 |
| 结算价 | 到期时的实际价格 |
| 投入金额 | 投入的 USDT 金额 |
| 结果 | 赢 / 输 / 平 |
| 实际收益 | 实际获得的收益 |
| 结算时间 | 结算时间 |

**统计信息：**

| 统计项 | 说明 |
|--------|------|
| 总投入 | 所有预测的总投入金额 |
| 总收益 | 所有预测的总收益金额 |
| 胜率 | 赢的次数 / 总次数 |
| 今日盈亏 | 今日已结算的盈亏 |

#### 4.2.4 High Low 特色功能

| 功能 | 说明 |
|------|------|
| 快速下单 | 高/低两个大按钮，简化决策流程 |
| 倒计时动画 | 到期前 10 秒显示倒计时动画效果 |
| 赔付计算器 | 输入投入金额实时显示预期收益 |
| 历史走势 | 显示最近 50 期的开奖结果走势图 |
| 交易情绪指标 | 显示其他用户的选择比例 |

### 4.3 High Low 界面差异

| 功能 | 与 Futures 差异 |
|------|----------------|
| 订单簿 | 无订单簿（做市商模式） |
| 杠杆 | 无杠杆概念 |
| 持仓方式 | 预测订单，非传统持仓 |
| 强平价格 | 无强平概念 |
| 下单按钮 | 高/低两个大按钮替代买入/卖出 |
| 时间选择 | 增加时间范围选择器 |
| ROI 显示 | 根据时间显示对应 ROI |

## 5. Spread（差价预测）全屏下单

### 5.1 业务特性

| 特性 | 说明 |
|------|------|
| 预测方式 | 预测两个资产之间的价差走势 |
| 交易时间 | 多个时间选择（1 分钟、5 分钟、15 分钟、30 分钟、1 小时） |
| 点差差异 | 不同交易时间对应不同点差 |
| ROI 差异 | 不同交易时间对应不同 ROI 收益率 |
| 配对交易 | 同时做多一个资产、做空另一个资产 |

### 5.2 全屏界面功能

#### 5.2.1 K 线图区域

| 功能 | 说明 |
|------|------|
| 价差图表 | 显示两个资产的价差走势（而非单个资产价格） |
| 均值线 | 显示历史价差均值线（白色虚线） |
| 标准差通道 | 显示标准差通道（布林带形式） |
| 入场价差 | 显示当前持仓的入场价差水平线 |
| 当前价差 | 实时显示当前价差数值 |

**价差图表模式：**

| 模式 | 说明 |
|------|------|
| 单图表模式 | 仅显示价差走势 |
| 双图表模式 | 同时显示 Asset A 和 Asset B 的价格走势 |
| 对比模式 | 两个资产价格走势叠加对比 |

#### 5.2.2 下单面板

**资产对选择：**

| 功能 | 说明 |
|------|------|
| Asset A | 选择第一个资产（如 BTC） |
| Asset B | 选择第二个资产（如 ETH） |
| 常用配对 | 显示常用资产对（BTC/ETH、SOL/AVAX 等） |

**时间选择：**

| 时间 | 点差 | ROI |
|------|------|-----|
| 1 分钟 | 0.5% | 80% |
| 5 分钟 | 0.8% | 85% |
| 15 分钟 | 1.0% | 90% |
| 30 分钟 | 1.2% | 95% |
| 1 小时 | 1.5% | 100% |

**下单区域：**

| 功能 | 说明 |
|------|------|
| 投入金额 | USDT 金额输入 |
| 预期收益 | 根据投入金额和 ROI 实时计算 |
| 价差扩大按钮 | 绿色按钮，预测价差会扩大 |
| 价差收窄按钮 | 红色按钮，预测价差会收窄 |
| 对冲比例 | 自动计算对冲比例（Hedge Ratio） |
| 一键配对 | 一键开/平配对仓位 |

**数据显示：**

| 数据 | 说明 |
|------|------|
| 当前价差 | 实时显示当前价差 |
| 入场价差 | 显示持仓的入场价差 |
| 价差偏离 | 当前价差相对入场价差的偏离百分比 |
| Z-Score | 显示价差的 Z-Score 值 |

#### 5.2.3 持仓记录（底部标签页）

**当前持仓列表字段：**

| 字段 | 说明 |
|------|------|
| 资产对 | Asset A / Asset B |

## 8. 异常处理

### 8.1 Futures 异常场景

| 场景 | 触发条件 | 处理方式 |
|------|---------|---------|
| 余额不足 | 金额 > 可用余额 | Toast 提示，阻断下单 |

| 高杠杆确认 | 杠杆 > 200x | 弹出确认弹窗 |
| 网络异常 | 下单失败 | Toast 提示，保留订单信息 |

| 网络异常 | 下单失败 | Toast 提示，保留订单信息 |

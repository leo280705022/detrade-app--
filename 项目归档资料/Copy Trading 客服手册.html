1Copy Trading 基础知识（必读）

1.1 什么是 Copy Trading？

Copy Trading（跟单交易）允许用户（跟单员）选择信任的交易员，在交易员下单时自动同步复制其交易操作。交易员正常交易即可，无需额外操作。跟单员盈利时，系统自动按比例分润给交易员。

1.2 两个核心角色

角色定义收益来源
交易员（Lead Trader）正常交易的用户。当其产生盈利时，系统自动从跟单员的盈利中抽取分润。自身交易盈利 + 跟单员盈利分润
跟单员（Copy Trader）选择交易员并设置跟单参数的用户。系统自动同步交易员的操作。交易盈利（扣除分润后）
客服要点：任何注册用户都可以成为交易员或跟单员，无需特殊资质。交易员申请不需要交易记录门槛。

1.3 四种交易玩法

玩法类型分润范围默认分润杠杆止损
Futures合约交易1% — 15%5%支持支持（按单笔订单）
Spread价差预测1% — 5%2.5%不支持支持（按总跟单金额）
High Low高低预测1% — 5%2.5%不支持支持（按总跟单金额）
Up Down涨跌预测1% — 5%2.5%不支持支持（按总跟单金额）
重要：四种玩法的交易员身份完全独立。用户在 Futures 中是交易员，不代表在 Spread 中也是。每种玩法需要分别申请。

1.4 分润机制一句话解释

分润规则：跟单员盈利时，交易员按设定比例从盈利中抽取分润。跟单员亏损时，交易员不获得任何分润。分润只从盈利中收取，不从本金或亏损中收取。

2高频 FAQ 速查表

以下是最常见的用户问题及标准回答，按频率排序。

Q1如何成为交易员？
A：进入 Copy Trade 页面 → 选择想成为交易员的玩法（如 Spread）→ 点击 "Apply Now" → 提交申请 → 等待平台审核。审核通过后即可成为交易员。
无需交易记录门槛，新注册用户也可以申请。
Q2如何跟单？
A：进入 Copy Trade 页面 → 切换到 "Copy Trader" Tab → 浏览交易员列表 → 点击想跟随的交易员卡片上的 "Copy Trade" → 在弹窗中设置跟单参数（杠杆、金额、止损等）→ 点击 "Copy Trade" 确认。
Q3分润是怎么计算的？
A：分润由交易员设定（Futures 1%-15%，其他玩法 1%-5%）。当您跟单盈利时，系统自动按该比例将盈利的一部分分给交易员。例如：交易员分润 12%，您盈利 100 USDT → 交易员获得 12 USDT，您获得 88 USDT。亏损时不收取分润。
Q4跟单后为什么没有同步交易？
A：请检查以下几点：
① 账户余额是否充足（需 ≥ 每笔跟单金额）
② 跟单总金额上限（Copy Amount）是否已用完
③ 是否已触发止损（Futures 按单笔订单止损，其他玩法按总跟单金额止损）
④ 在 Copy Overview → Ongoing 中确认跟单状态是否正常
如以上均正常，请联系客服进一步排查。
Q5如何停止跟单？
A：进入 Copy Trade 页面 → 点击 "Copy Overview" → 在 "Ongoing" Tab 中找到要停止的跟单仓位 → 关闭即可。关闭后仓位立即结算。
Q6如何修改分润比例？
A：仅交易员可以修改分润比例。路径：Copy Trade → 选择对应玩法 → Lead Trader Tab → My Lead → Profit Sharing Ratio → 输入新比例 → Save。修改后立即生效。
Q7最多可以跟多少人 / 被多少人跟？
A：每个交易员最多支持 400 个跟单员。跟单员可以同时跟随多个交易员（不同玩法分别计算）。
Q8杠杆怎么选？
A：仅 Futures 玩法支持杠杆。跟单时有两个选项：
① Copy Leader Trader's Leverage（推荐）：自动跟随交易员的杠杆倍数，交易员调整时自动同步
② Fixed Leverage：使用固定杠杆，不受交易员影响
Q9止损是怎么工作的？
A：所有玩法都支持止损，但机制不同：
Futures：按单笔订单止损。当某笔订单的亏损达到设定比例时，系统自动平掉该笔订单，其他订单不受影响。
Spread / High Low / Up Down：按总跟单金额止损。当累计亏损达到总跟单金额的设定比例时，系统停止跟单并触发止损。
止损比例范围 0%-90%，默认 50%。设为 0% 等于不设止损。
Q10一个账号可以同时做交易员和跟单员吗？
A：可以。同一用户可以在同一玩法中既是交易员又是跟单员，也可以在不同玩法中分别担任不同角色。

3跟单员常见问题处理

3.1 跟单未生效

优先级排查项处理方式
高账户余额不足确认余额 ≥ Latest Cost Per Order。引导用户充值。
高Copy Amount 已用完累计跟单金额达到上限后自动停止。引导用户调高 Copy Amount 或重新开始跟单。
中止损已触发检查 Copy Overview → Closed 中是否有已止损的仓位。
中交易员已关闭身份交易员关闭身份后不再接受新跟单，但已有仓位继续运行。
低系统延迟极端行情下可能有几秒延迟，通常自动恢复。
"您好，请先到 Copy Overview 页面检查您的跟单状态。如果显示 Ongoing 但无新交易，请确认您的账户余额是否充足，以及 Copy Amount 上限是否已用完。如果都正常，请提供您的钱包地址，我帮您进一步排查。"

3.2 跟单盈亏异常

可能原因排查方式
杠杆不同导致盈亏不同确认跟单员选择的是"跟随杠杆"还是"固定杠杆"。如果选择固定杠杆且与交易员不同，盈亏会不同。
分润扣除跟单员的 Net Profit 是扣除分润后的净值。如交易员分润 12%，跟单员盈利 100 USDT，实际获得 88 USDT。
滑点差异极端行情下跟单员成交价可能与交易员略有不同，属于正常现象。

3.3 如何查看跟单历史

引导路径：Copy Trade → Copy Overview → Closed Tab

  • Ongoing：进行中的跟单
  • Closed：已关闭的跟单（含止盈、止损、手动关闭）

5分润相关常见问题

Q分润什么时候结算？
A：分润在跟单员平仓结算时自动扣除。盈利部分按比例自动分配给交易员，无需手动操作。
Q亏损了还需要付分润吗？
A：不需要。分润只从盈利中收取。亏损时交易员不获得任何分润。
Q分润比例是谁设定的？
A：由交易员自行设定。交易员可以在 My Lead 面板中调整分润比例（Futures 1%-15%，其他玩法 1%-5%）。
Q交易员修改分润比例后，已有的跟单会受影响吗？
A：已有的跟单关系不会被解除，但新的交易将按新比例计算分润。
Q在哪里可以看到我的分润收入？
A：交易员进入 My Lead 面板，可以看到 Today's Earnings（今日分润）和 Net Profit（累计净收益）。

6账户与资金相关

Q跟单需要额外费用吗？
A：跟单本身不收取额外费用。仅在盈利时按交易员设定的比例支付分润。结算币种为 USDT。
Q跟单的资金安全吗？
A：跟单资金始终在用户自己的账户中，交易员无法直接操作跟单员的资金。系统仅根据交易员的交易信号自动同步下单。
QLatest Cost Per Order 和 Latest Copy Amount 有什么区别？
A：
Latest Cost Per Order：每笔跟单的最大金额。交易员每次下单时，系统按此金额为跟单员同步下单。
Latest Copy Amount：跟单总金额上限。累计跟单金额达到此值后自动停止跟单。
例如：Cost Per Order = 1 USDT，Copy Amount = 100 USDT，则最多跟单 100 笔。
QTrading Amount Limit Note 是什么？
A：这是一个提醒功能。勾选后，当跟单金额接近限制时，系统会发送通知提醒用户。

7操作引导话术模板

"您好！开始跟单很简单：\n1. 打开 Detrade → 点击顶部 'Copy Trade'\n2. 选择您感兴趣的玩法（Futures / Spread / High Low / Up Down）\n3. 浏览交易员列表，关注 30 Days PnL（盈利）、ROI（回报率）和 MDD（风险）\n4. 点击满意的交易员卡片上的 'Copy Trade'\n5. 设置跟单金额和止损比例 → 确认即可\n\n建议先用小金额试单，熟悉后再增加。"

7.2 引导用户申请交易员

"您好！申请成为交易员：\n1. 进入 Copy Trade 页面\n2. 选择您想成为交易员的玩法\n3. 点击页面上的 'Apply Now' 按钮\n4. 提交申请后等待审核\n\n申请不需要交易记录门槛，新用户可以申请。每种玩法需要分别申请。审核通过后，其他用户就能看到您的交易数据并跟随您了。"

7.3 引导用户处理跟单异常

"您好，了解您的跟单可能出现了异常。请帮我确认以下信息：\n1. 您使用的是哪种玩法？（Futures / Spread / High Low / Up Down）\n2. 请打开 Copy Overview 页面，检查 Ongoing 中是否有进行中的跟单\n3. 请确认您的账户余额是否充足\n4. 请检查 Copy Amount 上限是否已用完\n\n请提供您的钱包地址和具体的交易员 ID，我帮您进一步排查。"

7.4 解释分润机制

"分润机制很简单：\n- 当您跟单盈利时，系统自动按交易员设定的比例（如 12%）将盈利的一部分分给交易员\n- 例如您盈利 100 USDT，分润 12% → 交易员获得 12 USDT，您获得 88 USDT\n- 如果您亏损，交易员不会获得任何分润\n- 分润在平仓时自动结算，不需要您手动操作"

8升级处理流程

8.1 需要升级的问题类型

问题类型升级对象需提供的信息
跟单同步完全失败（非余额/限额问题）技术支持用户钱包地址、交易员 ID、玩法、时间戳
分润金额计算异常技术支持 + 财务用户钱包地址、跟单记录截图、预期 vs 实际分润
交易员审核超时（>48h）运营团队用户钱包地址、申请时间、玩法
用户投诉交易员行为运营 + 风控用户举报内容、交易员 ID、相关证据
资金异常（余额变动与交易不符）技术支持 + 财务用户钱包地址、交易记录截图、异常金额

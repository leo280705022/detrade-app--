# DeTrade 充值页面重构 PRD

> 版本：V1.0 | 日期：2026-06-17 | 状态：待评审

---

## 1. 背景与目标

### 1.1 现状问题

当前 DeTrade 充值功能存在以下核心问题：

- **页面割裂**：Crypto 充值与法币充值分为 2 个独立 Tab 页面，用户需切换操作，体验不连贯
- **布局冗余**：同一页面内存在重复的"预期收益"模块（图 3 中出现两次），信息层级混乱
- **专业度不足**：
  - 缺少充值记录/历史入口
  - 缺少网络费用、到账时间等关键信息展示
  - 法币充值支付方式展示不够直观（仅卡片式排列，缺少费率、到账时间对比）
  - 缺少 Memo/Tag 提示（XRP、TON 等币种必需）
  - 缺少充值状态实时追踪
- **视觉一致性差**：Crypto 与法币页面风格不统一，按钮样式、信息密度不一致

### 1.2 重构目标

| 目标维度 | 具体指标 |
|---------|---------|
| **统一体验** | Crypto + 法币合并为 1 个页面，通过 Tab 切换，减少用户认知负担 |
| **专业对标** | 对齐 Binance / OKX / Bybit 等头部 CEX 的充值页面设计标准 |
| **信息完整** | 补充网络费用、到账时间、Memo/Tag、充值记录等关键信息 |
| **转化率提升** | 优化充值流程，减少操作步骤，提升首次充值转化率 |

## 3. 功能需求详细说明

### 3.1 顶部导航栏

| 字段 | 说明 |
|------|------|
| 返回按钮 | 点击返回上一页 |
| 标题 | "充值" |
| 关闭按钮 | 点击关闭充值弹窗/页面 |

### 3.2 充值方式 Tab

| Tab | 说明 | 默认选中 |
|-----|------|---------|
| 加密货币 | 链上充值，选择币种+网络 | ✅ 是 |
| 法币 | 法币入金，选择法币+支付方式 | ❌ 否 |

**交互规则**：
- Tab 切换时保留各自已填写的数据（金额、币种等）
- Tab 样式：选中态高亮（主色），未选中态灰色
- 支持左右滑动切换（移动端）

### 3.3 加密货币充值模块

#### 3.3.1 币种选择器

| 字段 | 说明 |
|------|------|
| 标签 | "币种" |
| 默认值 | USDT（或用户上次选择的币种） |
| 交互 | 点击弹出币种选择面板 |
| 搜索 | 支持按币种名称/代码搜索 |
| 排序 | 最近使用 > 热门币种 > 字母序 |
| 展示 | 币种图标 + 名称 + 代码，如 `Tether USD (USDT)` |

**热门币种列表**（默认展示）：
USDT, BTC, ETH, BNB, SOL, XRP, USDC, DOGE, ADA, TRX

#### 3.3.2 网络选择器

| 字段 | 说明 |
|------|------|
| 标签 | "网络" |
| 默认值 | 该币种的首选网络（如 USDT → TRC20） |
| 依赖 | 根据所选币种动态加载可用网络 |
| 展示 | 网络图标 + 网络名称，如 `TRON (TRC20)` |
| 附加信息 | 每个网络显示：网络费用 + 预计到账时间 |

**网络信息展示格式**：
```
TRON (TRC20)          费用: ~1 USDT    ~3 分钟
Ethereum (ERC20)      费用: ~5 USDT    ~10 分钟
BNB Smart Chain       费用: ~0.3 USDT  ~3 分钟
```

#### 3.3.3 奖励 Banner

| 字段 | 说明 |
|------|------|
| 文案 | "首次存款红利最高可达200%" |
| 图标 | 礼物/金币图标 |
| 样式 | 绿色渐变背景，与现有设计保持一致 |
| 交互 | 可点击跳转至活动详情页 |

#### 3.3.4 金额输入区

| 字段 | 说明 |
|------|------|
| 标签 | "充值金额" |
| 输入框 | 数字输入，支持小数 |
| 后缀 | 币种代码（如 USDT） |
| 最低充值 | 显示在输入框下方，如 "最低充值：10 USDT" |
| 校验 | 输入金额 < 最低充值时，显示红色错误提示 |

**快捷金额按钮**：
- 默认展示 5 个档位：30, 50, 100, 200, 500
- 点击快捷金额自动填入输入框
- 快捷金额根据币种动态调整（法币与 Crypto 档位不同）
- 保留现有的奖励比例标签（+50%, +100%, +150%, +200%）

#### 3.3.5 充值地址区

| 字段 | 说明 |
|------|------|
| QR 码 | 显示充值地址对应的二维码 |
| 地址标签 | "充值地址" |
| 地址值 | 完整地址，支持一键复制 |
| 复制按钮 | 点击复制地址到剪贴板，显示"已复制"反馈 |
| 网络提示 | "仅将 {币种} 发送到 {网络} 网络，需要 {N} 次确认" |
| Memo/Tag | 条件显示：当币种需要 Memo 时（XRP, EOS, TON 等），显示 Memo 输入框+复制按钮 |

**Memo/Tag 强提示**：
```
⚠️ 重要提示
该币种需要填写 Memo/Tag，否则可能导致资产丢失。
Memo: 123456789  [复制]
```

#### 3.3.6 费用与到账时间

| 字段 | 说明 |
|------|------|
| 网络费用 | 显示当前选择网络的预估费用 |
| 预计到账 | 显示预计到账时间范围 |
| 确认次数 | 显示需要的区块链确认次数 |

#### 3.3.7 充值记录入口

| 字段 | 说明 |
|------|------|
| 文案 | "查看充值记录 →" |
| 位置 | 地址区下方 |
| 交互 | 点击跳转至充值记录页面 |

### 3.4 法币充值模块

#### 3.4.1 法币选择器

| 字段 | 说明 |
|------|------|
| 标签 | "法币" |
| 默认值 | 根据用户所在地区自动选择（如尼日利亚 → NGN） |
| 交互 | 点击弹出法币选择面板 |
| 搜索 | 支持按法币名称/代码搜索 |
| 展示 | 国旗图标 + 法币名称 + 代码 |

#### 3.4.2 支付方式选择区

**展示方式**：卡片网格布局（2 列），每张卡片包含：

| 字段 | 说明 |
|------|------|
| 支付方式图标 | 银行/银行卡/电子钱包/P2P 图标 |
| 支付方式名称 | 如 "Bank Transfer"、"Card Payment" |
| 服务商名称 | 如 "PalmPay"、"Flutterwave" |
| 金额范围 | 如 "1,000 - 10,000,000 NGN" |
| 手续费 | 如 "免费"、"1.5%" |
| 到账时间 | 如 "~10 分钟"、"即时" |
| 选中态 | 边框高亮（主色） |

**支付方式类型**：

| 类型 | 图标 | 说明 |
|------|------|------|
| 银行转账 | 🏦 | 通过银行转账入金，免费或低费率 |
| 银行卡 | 💳 | Visa/Mastercard 直接支付，即时到账 |
| 电子钱包 | 📱 | PalmPay、OPay 等本地电子钱包 |
| P2P 交易 | 🔄 | 点对点交易，支持更多支付方式 |

#### 3.4.3 注意事项区

| 字段 | 说明 |
|------|------|
| 标题 | "注意事项" |
| 内容 | 动态展示，根据选择的支付方式显示对应注意事项 |
| 样式 | 浅灰色背景，带警告图标 |

**通用注意事项**：
1. 您的转账金额必须与提交的金额一致
2. 每个订单 ID 只能使用一次，以避免重复
3. 请按照充值指南进行充值，否则您的款项可能会丢失

#### 3.4.4 CTA 按钮

| 字段 | 说明 |
|------|------|
| 文案 | 动态生成，如 "通过 Bank Transfer 充值" |
| 样式 | 主色全宽按钮 |
| 交互 | 点击后进入支付流程（跳转第三方支付/显示银行信息） |

## 4. 交互流程

### 4.1 加密货币充值流程

```
用户进入充值页面
    ↓
默认显示「加密货币」Tab
    ↓
选择币种（默认 USDT）
    ↓
选择网络（默认首选网络，显示费用+到账时间）
    ↓
输入充值金额 / 点击快捷金额
    ↓
显示充值地址 + QR 码
    ↓
（如需 Memo）显示 Memo 强提示
    ↓
用户复制地址 → 前往外部钱包转账
    ↓
等待区块链确认 → 到账
```

### 4.2 法币充值流程

```
用户切换至「法币」Tab
    ↓
选择法币（根据地区自动选择）
    ↓
输入充值金额
    ↓
选择支付方式（显示费率+到账时间）
    ↓
点击 CTA 按钮 → 进入支付流程
    ↓
（银行转账）显示银行信息 + 参考码
    ↓
（银行卡）跳转第三方支付页面
    ↓
完成支付 → 等待到账
```

## 6. 异常处理

| 场景 | 处理方式 |
|------|---------|
| 输入金额 < 最低充值 | 输入框下方显示红色错误提示："最低充值金额为 X" |
| 输入金额 > 最高限额 | 输入框下方显示红色错误提示："最高充值金额为 X" |
| 网络维护中 | 网络选择器中该网络置灰，显示"维护中"标签 |
| 币种暂停充值 | 币种选择器中该币种置灰，显示"暂停充值"标签 |
| 复制地址成功 | Toast 提示"地址已复制" |
| 复制 Memo 成功 | Toast 提示"Memo 已复制" |
| 法币支付方式不可用 | 支付方式卡片置灰，显示"暂不可用" |
| 用户未 KYC | 法币 Tab 显示"请先完成身份认证"提示，引导至 KYC 页面 |

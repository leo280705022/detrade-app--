# 普通用户邀请管理 PRD

## 一、需求背景

为后管代理中心新增普通用户间的邀请返佣管理功能。普通用户A邀请普通用户B后，B在交易过程中产生的交易将通过返佣机制给予A佣金奖励。

### 返佣模式说明

| 返佣模式 | 适用玩法 | 返佣比例 |
|---------|---------|---------|
| PPL | Futures, HighLow, Spread, TapTrading | 0.3% |
| UPDOWN | Updown | 50% |

---

## 二、功能结构

```
普通邀请管理
├── 用户邀请数据看板（统计卡片）
├── 邀请人列表
│   └── 筛选区（名称、UID、邀请码）
│   └── 列表字段（名称、UID、邀请码、邀请人数、团队充值总额、团队账户余额、平台利润、已发放返佣）
│   └── 操作按钮（团队详情）
└── 团队详情页面（新标签页打开）
    ├── 筛选区（名称、UID、受邀时间范围）
    ├── 团队成员列表
    │   └── 列表字段（名称、UID、受邀日期、充值总额、账户余额、平台利润、产生佣金）
    │   └── 操作按钮（查看明细）
    └── 交易明细弹窗
        ├── 受邀人基本信息
        ├── 佣金概览（Futures/HighLow/Spread/TapTrading/Updown）
        └── 交易记录列表（支持玩法筛选）
```

## 四、计算公式

### 4.1 PPL模式返佣计算

**适用范围**：Futures、HighLow、Spread、TapTrading

#### 计算公式

```
单笔交易佣金 = 交易金额 × PPL返佣比例
```

**PPL返佣比例**：0.3%

#### 计算示例

| 交易流水号 | 玩法 | 交易金额(USDT) | 佣金比例 | 佣金(USDT) |
|-----------|------|---------------|---------|-----------|
| TRD202605150001 | Futures | 10,000 | 0.3% | 30.00 |
| TRD202605150003 | HighLow | 5,000 | 0.3% | 15.00 |
| TRD202605150005 | Spread | 8,000 | 0.3% | 24.00 |
| TRD202605150007 | TapTrading | 5,267 | 0.3% | 15.80 |

#### 单个玩法佣金汇总

```
Futures佣金 = Σ(Futures交易金额 × 0.3%)
HighLow佣金 = Σ(HighLow交易金额 × 0.3%)
Spread佣金 = Σ(Spread交易金额 × 0.3%)
TapTrading佣金 = Σ(TapTrading交易金额 × 0.3%)
```

### 4.2 UPDOWN模式返佣计算

**适用范围**：Updown

#### 计算公式

```
单笔交易佣金 = 交易盈亏 × UPDOWN返佣比例
```

**UPDOWN返佣比例**：50%

#### 计算示例

| 交易流水号 | 玩法 | 交易盈亏(USDT) | 佣金比例 | 佣金(USDT) |
|-----------|------|---------------|---------|-----------|
| TRD202605150008 | Updown | 1,200 | 50% | 351.28 |

> 注：Updown佣金计算基于平台从该交易中获得的利润，而非用户盈亏金额。实际计算时应使用平台利润作为基数。

#### 完整计算公式

```
Updown佣金 = Σ(Updown交易平台利润 × 50%)
```

### 4.3 总佣金计算

#### 单个受邀人总佣金

```
总佣金 = Futures佣金 + HighLow佣金 + Spread佣金 + TapTrading佣金 + Updown佣金
```

#### 单个邀请人已发放返佣

```
已发放返佣 = Σ(所有受邀人总佣金)
```

#### 全局总佣金

```
总佣金 = Σ(所有邀请人已发放返佣)
```

### 4.4 平台净盈利计算

#### 单笔交易平台净盈利

```
PPL模式平台净盈利 = 交易金额 × 平台抽成比例 - 佣金
UPDOWN模式平台净盈利 = 交易平台利润 × (1 - UPDOWN返佣比例)
```

#### 受邀人平台净盈利

```
平台净盈利 = Σ(PPL模式平台净盈利) + Σ(UPDOWN模式平台净盈利)
```

#### 全局平台净盈利

```
平台净盈利 = Σ(所有受邀人平台净盈利)
```

### 4.5 团队数据计算

#### 团队充值总额

```
团队充值总额 = Σ(所有受邀人充值总额)
```

#### 团队AUM

```
团队AUM = Σ(所有受邀人当前余额 + 所有受邀人持仓价值)
```

#### 剩余资金

```
剩余资金 = 团队AUM - 冻结资金
```

## 五、数据流转图

```
用户A邀请用户B
    ↓
建立邀请关系（记录inviter_uid, invitee_uid, invite_date）
    ↓
用户B进行交易
    ↓
系统根据玩法类型计算佣金
    ├── PPL模式（Futures/HighLow/Spread/TapTrading）
    │   └── 佣金 = 交易金额 × 0.3%
    └── UPDOWN模式（Updown）
        └── 佣金 = 交易平台利润 × 50%
    ↓
更新统计数据
    ├── 邀请人：已发放返佣、团队数据
    ├── 受邀人：产生佣金、平台利润
    └── 全局：平台净盈利、总佣金
    ↓
在后管页面展示
```

## 六、异常处理

### 6.1 数据异常

| 场景 | 处理方式 |
|------|---------|
| 受邀人无交易记录 | 显示"暂无数据"，佣金金额显示为0 |
| 交易金额为0 | 佣金为0，正常显示 |
| 负盈亏交易（UPDOWN） | 佣金为0或负数（取决于平台规则） |

### 6.2 筛选异常

| 场景 | 处理方式 |
|------|---------|
| 筛选条件无匹配结果 | 显示"暂无数据"空状态 |
| 筛选条件为空 | 显示全部数据 |

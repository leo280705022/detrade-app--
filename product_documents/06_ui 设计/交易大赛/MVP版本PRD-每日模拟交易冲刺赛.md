# MVP 版本 PRD：Daily Demo Sprint 每日模拟交易冲刺赛

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 产品名称 | Daily Demo Sprint 每日模拟交易冲刺赛 |
| 产品模块 | 活动中心 / 交易大赛 / 模拟交易 |

## 2. 背景与目标

### 2.1 背景

Detrade 当前需要以活动形式上线交易大赛能力。首期不建议直接覆盖真金赛、团队赛、多玩法复杂榜单等全部能力，而应优先选择投入较低、风险较低、增长链路清晰的模拟金个人日赛。

模拟金日赛通过每日重置账户余额、每日排行榜、奖励解锁和首充引导，让用户形成“每天都有机会冲榜”的参与心智。

### 2.2 业务目标

- 提升每日活跃用户数。
- 提升模拟交易笔数和交易频次。
- 提升游客注册转化。
- 提升注册用户首充转化。
- 验证交易大赛活动模型、排行榜模型、奖励解锁模型。
- 为后续真金赛、团队赛、专项玩法赛预留扩展能力。

### 2.3 MVP 核心策略

MVP 只做一条完整闭环：后台配置活动，登录用户自动参赛，每日重置模拟账户，用户模拟交易，系统或运营生成排行榜，活动结束后人工审核，后台发放奖励或奖励解锁任务。

## 3. 用户范围

### 3.1 游客

- 可访问活动详情页。
- 可查看活动规则和排行榜。
- 点击开始冲榜、交易、领取奖励时引导注册或登录。
- 不可进入排行榜。

### 3.2 注册用户

- 登录后自动参与每日模拟交易冲刺赛，无需手动报名。
- 可使用模拟账户参与交易。
- 满足有效参赛条件后进入排行榜。
- 可获得排名奖励或幸运奖资格。

### 3.3 获奖用户

- 排名奖励用户需满足奖励解锁条件。
- 幸运奖用户需满足后台配置的发放或解锁规则。
- 若命中风控规则，奖励进入待审核或取消状态。

### 3.4 运营管理员

- 可在后管创建、编辑、上线、下线活动。
- 可配置赛事时间、模拟金余额、自动参赛规则、榜单规则、奖励规则、风控规则。
- 可查看访问、自动参赛、交易、排行、奖励、风控数据。
- 可执行结算、审核、发奖、取消资格、排名重算。

| 结算中 | 不再计入成绩，展示结算中 |
| 已结束 | 展示最终榜单和奖励结果 |
| 已下线 | 前端不展示 |

关键交互：

### 5.3 自动参赛流程

自动参赛条件：

- 用户已注册并登录。
- 活动处于进行中状态。
- 用户未命中黑名单。
- 用户所在地区未被限制。

自动参赛触发方式：

- 用户登录后进入活动页，系统展示当期赛事进度。
- 用户在活动期间完成第一笔符合交易范围的模拟交易后，系统自动生成当期参赛记录。
- 用户后续符合规则的模拟交易自动计入赛事统计。
- 用户满足有效参赛条件后自动进入排行榜。
- 前端提示“已开始记录你的比赛成绩，完成 10 笔模拟交易即可进入排行榜”。

不可参赛场景：

| 场景 | 提示文案 |
| --- | --- |
| 未登录 | 请先登录后开始冲榜 |
| 活动未开始 | 活动尚未开始，请稍后再来 |
| 活动已结束 | 活动已结束，明日可继续参赛 |
| 风控限制 | 当前账户暂不符合活动参与条件 |

### 5.4 模拟账户重置

规则：

- 每日 UTC 00:00 创建新一期赛事。
- 每期为符合自动参赛条件的登录用户提供赛事模拟初始余额。
- MVP 默认初始余额为 10,000 Demo USDT，后台可配置。
- 重置仅影响赛事统计口径，不强制清除用户全局模拟账户历史，具体由账户系统实现决定。
- 若采用赛事专用模拟账户，比赛结束后冻结该期账户快照。

前端展示：

- 今日模拟初始余额。
- 当前模拟余额。
- 今日盈利。
- 今日 ROI。
- 距离重置时间。

### 5.5 有效参赛条件

用户需同时满足以下条件后进入排行榜并具备获奖资格：

| 条件 | MVP 默认值 | 是否后台可配置 |
| --- | --- | --- |
| 登录状态 | 必须登录 | 是 |
| 模拟交易笔数 | ≥ 10 笔 | 是 |
| 参与玩法数量 | ≥ 2 种 | 是 |
| 累计模拟交易额 | ≥ 100U | 是 |
| 单笔最小金额 | ≥ 1U | 是 |
| 命中风控 | 不可获奖 | 是 |

未满足条件时：

- 可展示在“我的进度”中。
- 不进入公共排行榜。
- 可展示“还差 X 笔交易进入排行榜”。

### 5.6 排行榜

MVP 支持两个榜单：

- 盈利金额榜。
- ROI 榜。

盈利金额榜：

`当日盈利金额 = 当前赛事模拟余额 - 当期初始模拟余额`

ROI 榜：

`ROI = 当日盈利金额 / 当期初始模拟余额 × 100%`

排行榜展示字段：

| 字段 | 说明 |
| --- | --- |
| 排名 | 当前名次 |
| 用户 | 昵称或 UID 脱敏 |
| 盈利金额 | Demo USDT |
| ROI | 百分比 |
| 交易笔数 | 有效交易笔数 |
| 更新时间 | 榜单更新时间 |

我的排名固定卡片：

- 当前排名。
- 当前盈利。
- 当前 ROI。
- 有效交易笔数。
- 距离上一名差值。
- 是否满足入榜条件。

榜单刷新：

- MVP 支持手动刷新或定时离线刷新。
- 前端展示最近更新时间。
- 榜单文案需说明“实时榜单仅供参考，最终排名以结算审核结果为准”。

### 5.7 奖励展示

排名奖励：

| 排名 | 奖励 | 解锁条件 |
| --- | --- | --- |
| 第 1 名 | 最高 100 USDT 奖励金 | 首充 ≥ 10U，完成 10 笔真金交易 |
| 第 2-3 名 | 最高 50 USDT 奖励金 | 首充 ≥ 5U，完成 5 笔真金交易 |
| 第 4-10 名 | 最高 20 USDT 奖励金 | 首充 ≥ 2U，完成 2 笔真金交易 |
| 第 11-50 名 | 体验金或手续费券 | 完成 1 笔真金交易 |

幸运奖：

- 完成 20 笔模拟交易即可获得幸运奖抽取资格。
- 奖励为 1-5 USDT 或体验金，具体由后台配置。

奖励状态：

| 状态 | 说明 |
| --- | --- |
| 待结算 | 比赛未完成结算 |
| 待审核 | 排名已生成，等待风控或人工审核 |
| 待解锁 | 用户已获奖，但未完成首充或真金交易任务 |
| 可领取 | 已满足领取条件 |
| 已发放 | 奖励已到账 |
| 已失效 | 超过有效期未解锁或未领取 |
| 已取消 | 风控或违规取消 |

### 5.8 奖励解锁

MVP 可先支持运营人工审核和人工发放，但业务端需展示解锁条件。

解锁任务展示：

- 首充金额进度。
- 真金交易笔数进度。
- 奖励有效期。
- 去充值按钮。
- 去真金交易按钮。

### 5.9 空状态与异常状态

| 场景 | 展示 |
| --- | --- |
| 无排行榜数据 | 暂无用户入榜，完成有效交易即可冲榜 |
| 游客访问 | 登录后完成有效模拟交易即可自动参赛 |
| 未满足入榜条件 | 还差 X 笔交易 / X U 交易额进入排行榜 |
| 活动结算中 | 排名审核中，最终结果即将公布 |
| 活动已结束 | 本期已结束，明日可继续参赛 |
| 网络异常 | 数据加载失败，请重试 |

## 7. 数据口径

### 7.1 有效订单

有效订单需满足：

- 订单归属于当前赛事周期。
- 用户已登录，且符合自动参赛条件。
- 订单为模拟交易订单。
- 订单状态为已结算。
- 订单交易对在活动配置范围内。
- 订单玩法在活动配置范围内。
- 订单金额大于等于最小有效单笔金额。
- 订单未被风控排除。

### 7.2 盈利金额

`盈利金额 = 当前赛事模拟余额 - 当前赛事初始模拟余额`

若系统不采用独立赛事模拟账户，则按赛事有效订单累计盈亏计算：

`盈利金额 = 有效订单盈利总额 - 有效订单亏损总额`

### 7.3 ROI

`ROI = 盈利金额 / 当前赛事初始模拟余额 × 100%`

### 7.4 有效参赛用户

同时满足登录状态、最低交易笔数、最低交易额、最低玩法数量、未命中严重风控的用户。

### 7.5 幸运奖资格用户

完成后台配置的幸运奖门槛，MVP 默认完成 20 笔模拟交易。

## 8. 状态流转

### 8.1 活动状态

### 8.2 用户参赛状态

### 8.3 奖励状态

## 12. 验收标准

### 12.1 用户业务端

- 游客可查看活动，但开始冲榜、交易和领取奖励时必须登录。

- 用户完成第一笔符合规则的模拟交易后可看到我的赛事数据。
- 未满足入榜条件时展示进度提示。

- 盈利金额榜和 ROI 榜计算准确。

## 13. 风险与待确认事项

### 13.1 需要业务确认

- MVP 是否采用赛事专用模拟账户，还是基于用户现有模拟账户做赛事统计。
- 模拟初始余额默认值是否确定为 10,000 Demo USDT。
- 排名奖励是否以 USDT 奖励金、体验金、手续费券中的哪一种为主。
- 幸运奖是否 MVP 上线，还是第二阶段上线。
- 首充解锁条件是否需要在 MVP 前端展示并支持进度追踪。
- 榜单刷新是手动、定时离线，还是准实时。

### 13.2 产品风险

- ROI 榜随机性较强，需要门槛控制。
- 模拟赛奖励如果可直接提现，容易被薅羊毛。
- 手动结算效率有限，活动规模变大后需要自动结算。
- 风控能力不足时，不建议开放高额奖励。

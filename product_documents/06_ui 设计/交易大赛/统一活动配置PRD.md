# 交易大赛统一配置后台 PRD V3.0

## 1. 概述

本文档用于定义交易大赛统一配置后台的产品需求。运营可在该后台完成交易大赛的创建、查看、配置、名单管理、历史查看与发奖操作。

### 1.1 活动类型

**交易大赛**：平台预设排名奖励，用户按排行榜名次获得对应奖励。

### 1.2 产品目标

- 统一交易大赛的后台配置入口
- 降低运营配置成本，提升活动上线效率
- 规范活动的时间周期、门槛、排行榜和发奖配置
- 支持待开始状态下自由编辑配置，进行中自动锁定

---

## 2. 适用角色

| 角色 | 说明 |
| ---- | ---- |
| 运营 | 创建活动、配置规则、名单管理、查看历史、手动发奖 |
| 产品 | 设计活动模板、定义规则、校验原型与需求一致性 |
| 研发 / 测试 | 根据配置规则实现与验证活动逻辑 |

---

## 3. 页面结构总览

交易大赛统一配置后台包含以下主要模块：

1. 活动列表页
2. 新建 / 编辑 / 查看活动弹窗
3. 名单配置弹窗
4. 活动历史记录弹窗
5. 手动发奖确认弹窗

其中活动配置弹窗采用 **4 步步骤式配置**：

```text
步骤1：基础信息 → 步骤2：时间与周期配置 → 步骤3：参赛门槛 → 步骤4：奖池/奖励规则
```

## 5. 活动状态流转

### 5.1 状态定义

| 状态 | 枚举值 | 说明 |
| ---- | ------ | ---- |
| 待开始 | pending | 活动已创建但未到开始时间，可编辑配置 |
| 进行中 | active | 活动正在进行中，仅允许修改风控设置 |
| 已结束 | ended | 活动结束并完成结算 |

### 5.2 流转规则

| 触发条件 | 状态变更 |
| -------- | -------- |
| 新建活动 | 默认为「待开始」 |
| 到达活动展示开始时间 | 自动变更为「进行中」 |
| 活动结束并完成结算 | 自动变更为「已结束」 |

### 5.3 编辑权限

| 状态 | 配置可编辑 | 风控设置可编辑 |
| ---- | ---------- | -------------- |
| 待开始 | 是 | 是 |
| 进行中 | 否 | 是 |
| 已结束 | 否 | 否 |

### 7.1 字段说明

| 字段 | 控件类型 | 必填 | 说明 |
| ---- | -------- | ---- | ---- |
| 活动名称 | 输入框 | 是 | 如：BTC 周常交易大赛 |
| 活动副标题 | 输入框 | 否 | 如：每周模拟交易冲刺赛 |
| 赛事模式 | 下拉单选 | 是 | 模拟金 / 真金 |
| 赛事类型 | 下拉单选 | 是 | 个人赛 / 团队赛 |
| 适用平台 | 下拉单选 | 是 | cc / bc，默认值为 cc |
| 关联玩法配置 | 单选 | 是 | Futures / UpDown / HighLow / Spread / Tap Trading |
| 关联交易对 | 多选下拉 | 是 | 支持多交易对选择 |

2. 关联玩法配置当前为**单选**，不支持多选。
3. 关联交易对支持多选。
4. 查看模式下字段默认只读，但状态开关允许按规则操作。

### 7.3 状态说明

- 状态值：`active` / `inactive`
- 开关文案：开启 / 关闭
- 查看模式下切换状态时，应实时同步到列表数据

## 8. 步骤二：时间与周期配置

### 8.1 活动展示时间

| 字段 | 控件类型 | 必填 | 说明 |
| ---- | -------- | ---- | ---- |
| 活动展示开始时间 | 日期时间选择器 | 是 | 控制活动在前端的展示起始时间 |

### 8.2 周期模式

| 字段 | 控件类型 | 必填 | 选项 |
| ---- | -------- | ---- | ---- |
| 周期模式 | 下拉单选 | 是 | 单次 / 每小时 / 每日循环 / 每周循环 / 每月循环 / 自定义周期 |

### 8.3 时间配置规则

#### 8.3.1 单次模式

| 字段 | 控件类型 | 必填 | 说明 |
| ---- | -------- | ---- | ---- |
| 开始时间 | 日期时间选择器 | 是 | 手动选择 |
| 结束时间 | 日期时间选择器 | 是 | 手动选择 |

#### 8.3.2 非单次模式

| 字段 | 控件类型 | 必填 | 说明 |
| ---- | -------- | ---- | ---- |
| 开始时间 | 日期时间选择器 | 是 | 手动选择 |
| 结束时间 | 只读展示 | 否 | 根据周期模式自动计算，仅展示首期结束时间 |
| 自动生成下一期 | 开关 | 否 | 位于开始时间/结束时间同一行，仅非单次模式显示 |

自动生成下一期开关规则：

- 仅在非单次周期模式下显示
- 不受延期发放设置控制
- 查看模式下可直接切换，并实时同步，取最后一次设置状态

### 8.4 自定义周期

当周期模式为"自定义周期"时，显示：

| 字段 | 控件类型 | 必填 | 说明 |
| ---- | -------- | ---- | ---- |
| 自定义时长（小时） | 数字输入 | 是 | 用于自动计算结束时间 |

### 8.5 周期结束时间自动计算规则

| 周期模式 | 结束时间计算方式 |
| -------- | ---------------- |
| 每小时 | 开始时间 + 1 小时 |
| 每日循环 | 当日 23:59:59 |
| 每周循环 | 本周日 23:59:59 |
| 每月循环 | 本月最后一天 23:59:59 |
| 自定义周期 | 开始时间 + 自定义时长 |

### 8.6 延期发放设置

| 字段 | 控件类型 | 必填 | 说明 |
| ---- | -------- | ---- | ---- |
| 延期发放设置 | 开关 | 是 | 开启表示自动发放，关闭表示手动发放 |
| 延期时间 | 下拉单选 | 是 | 仅当开启自动发放时显示 |

延期时间选项：

- 延期 0H
- 延期 1H
- 延期 1 天

### 8.7 延期发放交互规则

1. 新建 / 编辑模式下可正常编辑。
2. 查看模式下：
   - 若活动状态为**进行中**，则可编辑延期发放设置；
   - 若关闭后重新开启，则可重新设置延期时间；
   - 若活动不是进行中，则该区域只读。
3. 延期发放设置与自动生成下一期开关相互独立。

## 10. 步骤四：奖池 / 奖励规则

本步骤包含三个配置区域：

1. 奖池累计配置
2. 排行榜设置
3. 排名奖励配置

### 10.1 奖池累计配置

| 字段 | 控件类型 | 说明 |
| ---- | -------- | ---- |
| 奖池累计方式 | 单选 | 平台出资 / 交易抽成 / 平台出资 + 交易抽成 |

#### 10.1.1 平台出资

当选择「平台出资」或「平台出资 + 交易抽成」时，显示：

| 字段 | 控件类型 | 必填 | 说明 |
| ---- | -------- | ---- | ---- |
| 平台出资金额 | 数字输入 | 是 | 平台为本次活动提供的出资金额 |

#### 10.1.2 交易抽成

当选择「交易抽成」或「平台出资 + 交易抽成」时，显示：

| 字段 | 控件类型 | 必填 | 说明 |
| ---- | -------- | ---- | ---- |
| 交易抽成比例 (%) | 数字输入 | 是 | 从用户交易手续费或净利润中抽取的比例 |

### 10.2 排行榜设置

| 字段 | 控件类型 | 选项 |
| ---- | -------- | ---- |
| 排名依据 | 单选 | 盈亏额 / 利润绝对值 / ROI / 单笔 ROI / 胜率 |

#### 10.2.1 算法说明

- **盈亏额**：统计用户盈利金额进行排行，`盈亏额 ≤ 0` 不计入排行榜。
- **利润绝对值**：`盈利绝对值 + 亏损绝对值`，结果恒为正数，用于衡量交易活跃度。
- **ROI**：`盈亏金额 / 下单金额 = ROI`，ROI 可为负数，但 `ROI ≤ 0` 不计入排行榜。
- **单笔 ROI**：使用 **Tap Trading** 玩法口径进行统计，`单笔 ROI ≤ 0` 不计入排行榜。
- **胜率**：`盈利单数 / 下单总数 = 胜率`，`胜率 ≤ 0` 不计入排行榜。

### 10.3 排名奖励配置

采用表格行内配置样式，支持动态增删。

#### 10.3.1 表头字段

| 字段 | 说明 |
| ---- | ---- |
| 名次范围 | 如 1-1、2-3、4-10 |
| 奖励类型 | 真金 / 奖励金 / 实物 / 优惠券 |
| 奖励金额/物品 | 根据奖励类型显示不同配置 |
| 操作 | 删除当前奖励区间 |

#### 10.3.2 奖励类型与对应配置

| 奖励类型 | 奖励金额/物品配置 | 说明 |
| -------- | ----------------- | ---- |
| 真金 | 百分比输入框（%） | 获得平台出资金额的百分比，校验总和不超过 100% |
| 奖励金 | 金额输入框（$） | 固定奖金金额，不归属于平台出资金额内 |
| 实物 | 图片上传 + 名称输入 + 价值输入（$） | 配置实物图片、名称、价值 |
| 优惠券 | 下拉选择 | 选择后管配置的优惠券 |

#### 10.3.3 操作规则

- 支持新增奖励区间（底部「+ 添加奖励区间」按钮）
- 支持删除奖励区间
- 至少保留 1 行奖励配置
- 查看模式下默认只读

#### 10.3.4 校验规则

- 真金奖励百分比总和不能超过 100%（当奖池累计方式包含平台出资时）
- 至少存在 1 条排名奖励配置

## 15. 排行榜与奖励计算规则

### 15.1 参赛有效性判断

用户交易记录是否进入排行榜统计，需同时满足：

1. 满足关联玩法配置
2. 满足关联交易对范围
3. 满足最小有效单笔金额 / 最大有效单笔金额限制
4. 满足最低交易笔数要求（若配置值大于 0）
5. 不在黑名单中

### 15.2 交易大赛奖励计算

- 先生成排行榜结果
- 按用户名次匹配对应奖励区间
- 读取奖励类型与奖励金额/物品
- 根据不同奖励类型执行发奖：
  - **真金**：按配置的百分比 × 平台出资金额
  - **奖励金**：按配置的固定金额发放
  - **实物**：发放配置的实物奖品
  - **优惠券**：发放配置的优惠券
- 奖励解锁并进入发奖流程

## 18. 校验与保存规则

### 18.1 保存时校验

- 至少存在 1 条排名奖励配置
- 奖励区间信息完整
- 奖励类型已选择
- 当奖池累计方式包含「平台出资」时，真金奖励百分比总和不能超过 100%
- 平台出资金额必须大于 0（当选择平台出资时）
- 交易对至少选择 1 个
- 玩法配置必须选择 1 个

### 18.2 通用规则

- 新建活动默认状态为「待开始」
- 时间字段应满足开始时间早于结束时间（单次模式）

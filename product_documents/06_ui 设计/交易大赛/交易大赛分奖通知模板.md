# 交易大赛分奖通知模板

## 模板一：获奖通知（站内信）

### 标题

🏆 恭喜您在 {competition_name} 交易大赛中获得第 {rank} 名！

### 内容

```

恭喜您在 {competition_name} 交易大赛中取得优异成绩！

- 大赛名称：{competition_name}
- 赛事模式：{mode}（{mode_text}）
- 赛事类型：{competition_type}
- 关联玩法：{game_type}
- 关联交易对：{trading_pairs}
```

## 使用场景说明

### 模板一：获奖通知（站内信）
- **触发时机**：交易大赛结算完成后，向获奖用户发送
- **目标用户**：所有获奖用户（前 N 名）
- **通知渠道**：站内信、APP Push
- **特点**：信息完整，包含获奖详情、奖励内容和解锁条件

### 模板二：幸运奖通知（站内信）
- **触发时机**：交易大赛结算完成后，向幸运奖获得者发送
- **目标用户**：完成规定交易笔数并参与抽奖的用户
- **通知渠道**：站内信、APP Push
- **特点**：简洁通知，突出幸运奖金额

### 模板三：邮件通知
- **触发时机**：交易大赛结算完成后，向获奖用户发送邮件
- **目标用户**：所有获奖用户
- **通知渠道**：邮件
- **特点**：格式正式，信息详尽，包含大赛信息、成绩、奖励和获奖名单公示

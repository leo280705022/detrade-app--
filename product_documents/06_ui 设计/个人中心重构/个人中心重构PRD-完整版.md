## 一、需求概述

### 1.1 背景

个人中心是用户管理资产、查看持仓、追踪交易记录的核心模块。本次重构旨在优化用户体验，提升信息展示效率，完善功能模块。

### 1.2 目标

- 重构资产中心，提供清晰的资产概览和趋势分析
- 优化持仓记录展示，支持分类统计和详细持仓信息
- 完善历史交易记录，支持多维度筛选和动态表头
- 实现完整的中英文国际化和深浅色主题切换

### 1.3 范围

本次重构包含三个核心模块：

1. **资产中心** - 资产概览、趋势分析、账户卡片、资产明细
2. **持仓记录** - 分类持仓展示、汇总统计、持仓操作
3. **历史交易** - 多类型交易记录、动态筛选、统计分析

#### 2.3.3 汇总统计区（位于Tab下方）

**布局结构**：

```
┌─────────────────────────────────────────────────────────┐
│ 总持仓金额          │ 总未实现盈亏        │ 持仓数量     │
│ 15,234.56           │ +1,234.56           │ 5            │
│ USDT                │ (+8.78%)            │ 笔           │
└─────────────────────────────────────────────────────────┘
```

**字段说明**：

| 字段     | 说明               | 数据来源 | 动态更新     |
| ------ | ---------------- | ---- | -------- |
| 总持仓金额  | 当前Tab下所有持仓的总金额   | 计算得出 | 切换Tab时更新 |
| 总未实现盈亏 | 当前Tab下所有持仓的未实现盈亏 | 计算得出 | 切换Tab时更新 |
| 持仓数量   | 当前Tab下的持仓笔数      | 计算得出 | 切换Tab时更新 |

**计算逻辑**：

- **合约持仓**：
  - 总持仓金额 = Σ(开仓本金)
  - 总未实现盈亏 = Σ(未实现盈亏)
- **预测持仓**：
  - 总持仓金额 = Σ(投注金额)
  - 总未实现盈亏 = 待结算持仓为0，已结算持仓计算实际盈亏
- **理财持仓**：
  - 总持仓金额 = Σ(投入本金)
  - 总未实现盈亏 = Σ(累计收益)

**交互逻辑**：

- 切换Tab时，重新计算并更新统计数据
- 盈亏颜色：正数绿色，负数红色
- 百分比显示在盈亏数值下方

```
💡 提示：

立即查看完整排行榜 >>

{platform_name} 团队
{notification_time}
```

## 使用场景说明

### 模板一：获奖通知（站内信）

- **触发时机**：奖池结算完成后，向获奖用户发送
- **目标用户**：所有获奖用户（前 N 名）
- **通知渠道**：站内信、APP Push、邮件
- **特点**：信息完整，包含所有获奖详情，用户体验好

### 模板四：平台公告（全员通知）

- **触发时机**：奖池结算完成后，向全体用户发送
- **目标用户**：平台所有用户
- **通知渠道**：站内信公告栏、APP 弹窗、Telegram 频道
- **特点**：公示分奖结果，增加透明度，吸引用户参与下期活动

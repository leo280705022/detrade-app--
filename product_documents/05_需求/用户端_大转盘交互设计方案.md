# 用户端 - 幸运大转盘交互设计方案 (Client-Side Design Spec)

## 1. 设计目标
*   **高频曝光**: 让用户容易发现转盘入口，消耗库存次数。
*   **爽感反馈**: 抽奖过程需具备物理真实感，中奖反馈需有冲击力。
*   **留存钩子**: 通过“剩余次数”和“下次抽奖倒计时”留住用户。

## 2. 入口设计 (Entry Points)

为了最大化触达，设计三个层级的入口：

| 优先级 | 位置 | 形态 | 交互逻辑 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| **L1 (强)** | **任务中心 (Task Center)** | 顶部 Banner / 进度条终点 | 显示“已有 X 次抽奖机会” | 用户完成任务后的直接去处 |
| **L2 (中)** | **首页 (Home) 悬浮窗** | 动态 GIF 图标 (宝箱/转盘) | 仅当`remain_times > 0`时出现 | 提醒用户消耗库存 |
| **L3 (弱)** | **我的页面 (Profile)** | 列表项 / 金刚区图标 | 常驻入口 | 方便用户查找历史记录 |

## 3. 核心界面设计 (The Wheel UI)

### 3.1 视觉风格
*   **主题**: 赛博朋克 / 霓虹赌场风格 (符合交易APP的“搞钱”调性)。
*   **配色**: 金色 (Gold) + 紫色 (Purple) + 红色 (Red)。

### 3.2 页面布局
1.  **Header**:
    *   沉浸式背景图。
    *   跑马灯 (Ticker): "恭喜 User***888 抽中 100 USDT"。
    *   规则按钮 (右上角)。
2.  **The Wheel (转盘主体)**:
    *   居中大圆盘，CSS 绘制扇形。
    *   中心指针 (固定向下或向上)。
    *   **核心交互**: 点击中心 "GO" 按钮触发旋转。
3.  **Control Panel (操作区)**:
    *   **剩余次数**: 高亮显示。
    *   **连抽选项**: "抽1次" vs "抽5次" (若库存充足)。
4.  **My Rewards (我的奖品)**:
    *   底部抽屉 (Bottom Sheet) 或下方列表。
    *   展示最近中奖记录。

## 4. 交互逻辑 (Interaction Logic)

### 4.1 抽奖流程
1.  **Idle (待机)**: 转盘缓慢自转 (呼吸感)，指针微动。
2.  **Spin (启动)**:
    *   用户点击 "GO"。
    *   前端扣减次数展示 (乐观更新)。
    *   请求后端 API `POST /api/wheel/spin`。
    *   **动画**: 
        *   加速阶段 (0-1s)。
        *   高速旋转 (1-3s, 期间等待接口返回)。
        *   **接口返回 targetIndex**。
        *   减速阶段 (3-5s, 使用 `cubic-bezier` 缓动定位到 targetIndex)。
3.  **Result (结果)**:
    *   转盘停止。
    *   弹出 **中奖 Modal** (光效爆炸 + 音效)。
    *   "再来一次" 按钮。

### 4.2 异常处理
*   **次数不足**: 点击 "GO" 弹出任务列表 Bottom Sheet，引导去完成任务。
*   **网络错误**: 旋转不停，30s 后提示“网络开小差了”，重置转盘。

## 5. 动效细节
*   **指针碰撞**: 每经过一个扇区边界，指针做一个轻微的 `rotate` 抖动。
*   **震动反馈**: 手机 Taptic Engine 配合指针碰撞震动 (Haptic Feedback)。

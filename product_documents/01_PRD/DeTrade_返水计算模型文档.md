# DeTrade 返水系统计算模型与示例表 (Rebate Calculation Model)

## 1. 核心规则定义

*   **返水比例 (Rebate Rate)**: $R = 5\%$
*   **返水周期**: $T = 7$ 天
*   **释放规则**:
    *   **Day 1 (T+1)**: 立即释放 $50\%$
    *   **Day 2 ~ Day 7 (T+2 ~ T+7)**: 剩余 $50\%$ 按线性权重释放
*   **线性权重 ($W_d$)**:
    *   剩余部分总份数: $1+2+3+4+5+6 = 21$ 份
    *   第 $d$ 天释放比例: $P_d = 50\% \times \frac{d}{21}$ (其中 $d \in [1, 6]$)

## 2. 计算公式

### 2.1 每日领取金额 ($C_n$)
第 $n$ 天领取的返水金额由过去 7 天产生的所有返水叠加而成：

$$
C_n = \sum_{k=1}^{n-1} \text{GetRelease}(Rebate_k, n-k)
$$

其中 $\text{GetRelease}(Amount, days\_passed)$ 函数定义为：
*   If $days\_passed == 1$: return $Amount \times 50\%$ (次日立即释放)
*   If $2 \le days\_passed \le 7$: return $Amount \times 50\% \times \frac{days\_passed - 1}{21}$ (线性解锁)
*   Else: return 0

### 2.2 每日返水基数 ($Base_n$)
$$
Base_n = \max(0, \text{Loss}_n - C_n)
$$
*注: 若当日已领取的返水金额超过了亏损额，基数为 0，不产生负返水。*

### 2.3 每日新增返水 ($Rebate_n$)
$$
Rebate_n = Base_n \times 5\%
$$

# 奖池瓜分活动 UI 设计方案 (User Side Design)

## 1. 核心理念
**“透明、实时、刺激”**
*   **透明**: 资金来源清晰（手续费/利润），分配规则一目了然。
*   **实时**: 奖池金额实时跳动，排名实时刷新，激发竞争欲。
*   **刺激**: 强调“大奖”归属，利用倒计时营造紧迫感。

## 2. 页面结构

### 2.1 入口卡片 (Widget)
*   **位置**: 交易页右侧边栏 / 首页活动区。
*   **展示**:
    *   **动态奖池**: 金色数字滚动 (e.g. `$1,234,567`)。
    *   **倒计时**: `02d 14h 23m 10s`。
    *   **我的排名**: `No. 5` (若未上榜显示 `--`)。
    *   **CTA**: “立即瓜分” -> 跳转详情页。

### 2.2 奖池详情页 (Main Page)

#### A. 头部: 奖池仪表盘 (Hero Section)
*   **背景**: 暗金流体动画，象征资金汇聚。
*   **核心数据**:
    *   `本期奖池总额`: 超大字体，带呼吸光效。
    *   `本期周期`: 2023.10.01 - 2023.10.07 (Weekly Round 42)。
    *   `倒计时`: 环形进度条展示。
*   **规则摘要**:
    *   “交易 BTC/USDT 合约，手续费 5% 注入奖池”。
    *   “按交易量排名，Top 1 独享 20%”。

#### B. 我的战绩 (My Stats)
*   **卡片式布局**:
    *   `我的排名`: No. 12 (距离上一名差 $50,000 交易量)。
    *   `我的贡献`: $1,200,000 Volume。
    *   `预计分润`: **$350.00** (根据当前排名动态计算)。
    *   **分享按钮**: 生成炫酷海报“我在 BTC 奖池排名 No.12，瓜分 $350!”。

#### C. 实时排行榜 (Live Leaderboard)
*   **Tab**: `本期排行` / `往期大奖`。
*   **列表**:
    *   **Top 3**: 特殊样式 (金/银/铜皇冠)，展示头像、昵称、交易量、**预计分润**。
    *   **4-100**: 紧凑列表，展示排名变化趋势 (⬆️⬇️)。
    *   **高亮**: 自己所在的行高亮显示，始终吸底或在列表中定位。

#### D. 底部操作栏 (Footer)
*   **去交易**: “立即交易 BTC/USDT 提升排名” (跳转交易页)。

## 3. 交互细节
*   **数字跳动**: 奖池金额每 3-5 秒通过 WebSocket 推送更新，且有数字翻滚动效。
*   **排名超越**: 当用户排名上升时，弹出 Toast “恭喜！您已超越 User_888，排名上升至 No.11”。
*   **历史回溯**: 点击“往期大奖”可下拉选择期数，查看历史 Top 榜单及自己的历史收益。

---

## 4. 视觉风格 (Visual Style)
*   **配色**: 黑金风格 (Black & Gold)。
    *   背景: `#0B0E11` (深黑)
    *   主色: `#FCD535` (Detrade 黄/金)
    *   辅助: `#10B981` (涨/正收益), `#EF4444` (跌/倒计时)
*   **字体**: DIN Condensed (数字)，Inter (文本)。
*   **图标**: 3D 质感金币、奖杯。
